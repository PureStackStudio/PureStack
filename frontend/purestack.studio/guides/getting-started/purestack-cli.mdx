# PureStack CLI

PureStack CLI launches **PureStack Forge**, PureStack's website builder. Start with a template, shape your project, and explore it live.

## Open Forge

With Node.js 22.12+ and npm installed, run this where you want to create your project:

```sh
npx purestack@latest init
```

The command starts Forge as a local PureStack website. Click the URL printed in your terminal and keep the terminal open while you explore.

## Make the first change

Open your project in your editor. Change the headline in `content/modules/content/landing.ts` and save. Your words appear on the live site.

| Make it yours | Start here |
| --- | --- |
| Words, sections, and buttons | `content/modules/content/landing.ts` |
| Site name, logo, and palette | `content/siteConfig.json` |
| Your story | `content/about.mdx` |
| Layouts and components | `content/modules/components/` |

Your project’s `README.md`, `AGENTS.md`, and `/guide/` show the way. [PureStack Component Tools](/guides/getting-started/vscode-extension/) helps you edit pages and components in VS Code.

## Come back and keep building

**Finish Forge** stops both local servers and keeps your project. Next time:

```sh
cd my-site
yarn dev
```

Replace `my-site` with your folder name. Skipped installation? Run `yarn install` first.

## Everyday commands

| Command | What it does |
| --- | --- |
| `yarn dev` | Open your site locally. Saved changes reload in your browser. |
| `yarn format` | Format your code, MDX components, and TypeScript templates. |
| `yarn check` | Check code quality and formatting. |
| `yarn test` | Run app tests while you work. |
| `yarn build` | Generate the complete site in `dist/dev`. |
| `yarn publish` | Prepare a clean release in `dist/publish`, ready for your host. |

Ready to go live? Follow the [deployment guide](/guides/publishing/deployment/).

<ExpandablePanel title="Need more control from the terminal?" variant="surface">
  <p>You can prefill Forge without skipping it:</p>

```sh
npx purestack@latest init my-site --title "My next idea"
```

  <p>
    Run <code>npx purestack@latest init --help</code> for template selection,
    preset options, Forge's host and port, and direct creation for scripts. For
    existing content, use commands such as
    <code>yarn purestack build --content ./content</code>.
  </p>

  <h3 id="build-generate-static-files">
    <code>build</code>: generate static files
  </h3>

  <p>
    Writes the complete site to <code>outDir</code>. Use <code>--clean</code> to
    empty it first or <code>--no-cache</code> to bypass persistent caches.
  </p>

  <h3 id="serve-preview-and-edit"><code>serve</code>: preview and edit</h3>

  <p>
    Watches edits and reloads your browser. <code>--port</code> changes the
    address; <code>--full-render</code> builds every page before browsing. To
    run a second server for the same site, add <code>--out 2</code> and another
    port: it builds into <code>outDir</code> with a <code>-2</code> suffix, such
    as <code>dist/site-2</code>.
  </p>

  <h3 id="publish-prepare-a-release-folder">
    <code>publish</code>: prepare a release folder
  </h3>

  <p>
    Cleans <code>publishDir</code> and prepares an optimized release locally.
    Set your public URL in
    <a href="/guides/getting-started/site-config/">site configuration</a>.
  </p>
</ExpandablePanel>
