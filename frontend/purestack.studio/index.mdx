<section class="section container faq-layout" aria-labelledby="faq-title">
  <div>
    <span class="eyebrow">A FEW GOOD QUESTIONS</span>
    <h2 id="faq-title">Good to know.</h2>
    <p class="faq-intro">A little more context<br />before your first commit.</p>
  </div>
  <div class="faq-list">
    <details>
      <summary>What can I build with PureStack?<span aria-hidden="true">+</span></summary>
      <p>
        Content sites, documentation, landing pages, product interfaces, dashboards, and
        admin tools. Start with static pages and add TypeScript browser apps where you
        need interaction.
      </p>
    </details>
    <details>
      <summary>How does interactivity work?<span aria-hidden="true">+</span></summary>
      <p>
        MDX components render to HTML during the build. For client-side state and events,
        mount a Regor application from a TypeScript entry point using RegorApp or
        PageScript. PureStack bundles that entry point and its dependencies for the
        browser.
      </p>
    </details>
    <details>
      <summary>Is this React MDX?<span aria-hidden="true">+</span></summary>
      <p>
        PureStack uses Regor MDX: Markdown with Regor components and directives. You can
        use the familiar .mdx extension or the explicit .rmdx extension. React components
        are not interchangeable with Regor components.
      </p>
