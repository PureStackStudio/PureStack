## Pick the right feedback

| Need | Component |
| --- | --- |
| Perform an action | [Btn](./buttons/) |
| Navigate somewhere | [BtnLink](./btn-link/) |
| Arrange related controls | [BtnGroup](./btn-group/) |
| Reveal alternatives | [BtnGroupDropDown](./btn-group-drop-down/) |
| Label status or metadata | [Badge](./badge/) |
| Explain a message in context | [AlertBox](./alert-box/) |
| Acknowledge a recent action | [ToastHost](./toast-host/) |
