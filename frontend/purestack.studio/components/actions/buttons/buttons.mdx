## Usage

Use `Btn` to trigger an action, submit a form, or reset input. It renders a native `button` and is available directly in PureStack MDX. Choose its tone, variant, size, and icon to fit the task.

<Panel tone="info" variant="surface">
  <strong>Static markup. Explicit interaction.</strong>
  <p>
    MDX renders components at build time. Use <code>RegorApp</code> to load a
    browser application when a button needs state or an event handler. The
    interaction example below includes the app mount and complete TypeScript
    source.
  </p>
</Panel>

## Accessibility

- Use a visible, specific label such as “Save project”.
- Give icon-only controls an accessible name with `ariaLabel`.
- A disabled button cannot be activated or reached with Tab. Use visible context to explain why an action is unavailable.
- Keep navigation as links, including links styled as buttons.
- Use bound booleans such as `:disabled="false"` when supplying boolean values through MDX.

### Button behavior

Use native form behavior and boolean state to control what the action can do.

<ApiProperty
  anchor="btn-type"
  name="type"
  valueType="BtnType"
  defaultValue="button"
>
  <p>
    Chooses how the button interacts with its form. Unlike a bare HTML button,
    <code>Btn</code> defaults to <code>button</code>.
  </p>
  <dl class="api-choices">
    <dt><code>button</code></dt>
    <dd>Runs a click handler without submitting the form.</dd>
    <dt><code>submit</code></dt>
    <dd>Validates and submits its associated form.</dd>
    <dt><code>reset</code></dt>
    <dd>Resets its associated form.</dd>
  </dl>
  <p>
    <a href="#submit-and-reset"
      >Try submit and reset with reactive form state</a
    >
  </p>
```html
<Btn type="submit">Save project</Btn>
```
</ApiProperty>

<ApiProperty
  anchor="btn-disabled"
  name="disabled"
  valueType="boolean"
  defaultValue="false"
>
  <p>
    Prevents activation and removes the button from keyboard tab order. Accepts
    <code>true</code> or <code>false</code>.
  </p>
  <Flex
    class="api-demo"
    wrap="true"
    aria-label="Enabled and disabled comparison"
  >
    <Btn tone="accent">Available</Btn>
    <Btn tone="accent" :disabled="true">Unavailable</Btn>
  </Flex>
  <p class="api-note">
    Bind booleans with <code>:</code>. The string <code>"false"</code> is not a
    boolean. Explain why an action is unavailable in nearby visible text.
  </p>
```html
<Btn :disabled="true">Unavailable</Btn>
```
</ApiProperty>

### Native attributes

Extra attributes pass through to the native `<button>`. Add `id`, `class`, `name`, `value`, `form`, `title`, `data-*`, or `aria-*` directly. Custom classes are added alongside theme classes.

```html
<Btn
  type="submit"
  form="project-editor"
  name="intent"
  value="save"
  aria-describedby="save-help"
>
  Save project
</Btn>
```
