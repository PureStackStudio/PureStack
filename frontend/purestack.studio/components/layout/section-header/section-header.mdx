## Styling each layer

SectionHeader has no tone or variant props. Style its four text layers with eyebrowClass, titleClass, subtitleClass, and footnoteClass. titleId creates a linkable title; the default slot adds supporting content after the text.


```html
<div class="component-recipe">
<SectionHeader eyebrow="THE WORKSPACE" title="A home for your next idea" subtitle="Arrange the essentials, then make room for what comes next." footnote="Updated with the latest design review." titleTag="h3" titleId="workspace-heading" eyebrowClass="mb-2" titleClass="fs-h3 mb-2" subtitleClass="mb-3" footnoteClass="mb-3">
<Badge tone="feature">12 projects</Badge>
</SectionHeader>
</div>
```

## Behavior and accessibility

Choose heading levels in order. Visual size and heading semantics are independent. Empty text props omit their blocks; avoid empty headings and do not use the eyebrow as the only label.
