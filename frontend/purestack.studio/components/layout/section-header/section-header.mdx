## Fit the document hierarchy

Use h3 when the header belongs inside a section. Utility classes adjust appearance without changing semantics.

## Behavior and accessibility

Choose heading levels in order. Visual size and heading semantics are independent. Empty text props omit their blocks; avoid empty headings and do not use the eyebrow as the only label.

<ApiProperty anchor="section-header-prop-eyebrow" name="eyebrow" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Short context above the heading, such as a category or release label.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-subtitle" name="subtitle" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting text beneath the title.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-footnote" name="footnote" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting note below the section description.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-titleTag" name="titleTag" valueType="RefOrValue&lt;string&gt;" defaultValue="h2">
  <p>Heading element. Accepts h1–h6, p, div or span; invalid values fall back to h2. Match the surrounding document hierarchy.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-titleId" name="titleId" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Id on the title element. Reference it from the surrounding section with aria-labelledby.</p>
</ApiProperty>

<ApiProperty anchor="section-header-prop-footnoteClass" name="footnoteClass" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
