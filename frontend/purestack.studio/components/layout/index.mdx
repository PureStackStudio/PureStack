# Layout and content

<p class="component-directory-lead">Give every piece of content a place to belong.</p>

Build the structure, establish the hierarchy, then reveal details when they matter. Eleven focused components share the same theme and compose into complete interfaces. Each guide shows real compositions and every supported appearance or layout option.

## Pick the right structure

| Need | Components |
| --- | --- |
| Arrange a row, column, or toolbar | [Flex](./flex/) |
| Place content in responsive tracks | [Grid](./grid/) |
| Group content on a semantic surface | [Panel](./panel/) |
| Introduce a section | [SectionHeader](./section-header/) |
| Reveal supporting details | [ExpandablePanel](./expandable-panel/) |
| Add a visual cue | [Icon](./icon/) and [IconFrame](./icon-frame/) |
| Switch between related views | [Tabs](./tabs/) and [TabPane](./tab-pane/) |
| Focus on a separate task | [Modal](./modal/) and [ModalTrigger](./modal-trigger/) |
