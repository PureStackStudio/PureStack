Each base prop has Sm, Md, Lg, and Xl overrides. Values apply from that breakpoint upward and inherit the smaller value when omitted. Resize the page to inspect this complete configuration.

## Behavior and accessibility

Reversed directions change visual order, not reading or keyboard order. Prefer source order that makes sense without CSS. Breakpoint props inherit the smaller layout until an explicit override applies.
