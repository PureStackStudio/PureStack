## Interactive playground

Start with a preset, then change the column counts, gap, item alignment, and packing. Choose **Auto-fit cards** and reduce the preview width to see cards wrap without a media query. Choose **Dense board**, then turn dense packing off to compare how later items fill earlier gaps.

Responsive overrides use the browser viewport, not the preview width. Resize your browser to cross a breakpoint; the live readout shows which setting applies. Empty overrides inherit the smaller breakpoint. Spacing uses the framework's gap utilities. Wide cards use the same `layout-featured-card` class as the guide's spanning examples, starting at sm.

## Tracks, containers, and every breakpoint

Columns accept a number, a numeric string, or a CSS track expression. Omitted responsive values inherit the smaller breakpoint. Custom gaps and spans belong to CSS classes or native style attributes.

## Behavior and accessibility

Keep DOM order meaningful. Dense placement can fill earlier gaps but may make visual order differ from keyboard and reading order. Use `minmax(0, 1fr)` for shrinkable content tracks. Breakpoints use the active theme.

<ApiProperty anchor="grid-prop-container" name="container" valueType="RefOrValue&lt;string&gt;" defaultValue="div">
  <p>HTML element used as the layout root. Choose a semantic element such as section, nav or ul when its children fit that structure.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-columns" name="columns" valueType="RefOrValue&lt;number | string&gt;" defaultValue="1">
  <p>Column count from 1 to 12, or a CSS track list such as minmax(0, 1fr) auto. Numeric counts are clamped.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-columnsSm" name="columnsSm" valueType="RefOrValue&lt;number | string&gt;" defaultValue="inherits columns">
  <p>Column count or CSS track list at the theme’s sm breakpoint and above.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-columnsMd" name="columnsMd" valueType="RefOrValue&lt;number | string&gt;" defaultValue="inherits smaller breakpoint">
  <p>Column count or CSS track list at the theme’s md breakpoint and above.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-columnsLg" name="columnsLg" valueType="RefOrValue&lt;number | string&gt;" defaultValue="inherits smaller breakpoint">
  <p>Column count or CSS track list at the theme’s lg breakpoint and above.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-columnsXl" name="columnsXl" valueType="RefOrValue&lt;number | string&gt;" defaultValue="inherits smaller breakpoint">
  <p>Column count or CSS track list at the theme’s xl breakpoint and above.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-alignItems" name="alignItems" valueType="RefOrValue&lt;GridAlignItems&gt;" defaultValue="stretch">
  <p>Alignment inside each grid area: stretch, start, center or end.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-justifyItems" name="justifyItems" valueType="RefOrValue&lt;GridJustifyItems&gt;" defaultValue="stretch">
  <p>Inline alignment inside each grid area: stretch, start, center or end.</p>
</ApiProperty>

<ApiProperty anchor="grid-prop-dense" name="dense" valueType="RefOrValue&lt;boolean | string&gt;" defaultValue="false">
  <p>Enables CSS grid-auto-flow: row dense. Accepts true or the string true; use a boolean binding for clarity.</p>
</ApiProperty>
