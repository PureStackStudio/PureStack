## Feature map

| Feature | Where to try it |
| --- | --- |
| Reactive data and custom colors | Edit categories and values; compare the gains/losses, categorical, and single-accent palettes. |
| Tone, variant, and variantMode | Use the three appearance controls; every option also appears in the galleries. |
| Accessible name and description | The live chart binds ariaLabel to its exact-value summary; title and description are SVG metadata. |
| Empty label | Choose Empty data; a dedicated empty sample is also visible above. |
| Units | Change the value suffix in the live editor. |
| Size | Change width and height; blank width preserves responsive sizing. |
| Entrance motion | Toggle entrance animation; it is an entrance effect, rather than value interpolation. |
| Domain | Change minimum and maximum bounds. The range includes zero and every data value. |

## Behavior and accessibility

Each valid item is a category. Non-finite values are removed; negative values extend below zero. SVG title and description help describe the chart, but include nearby text or a data table for exact values. Turn animation off when comparing rapid updates.

<ApiProperty anchor="bar-chart-prop-items" name="items" valueType="RefOrValue&lt;Array&lt;RefOrValue&lt;BarChartItem&gt;&gt;&gt;" defaultValue="[]">
  <p>Array of BarChartItem objects with optional label, numeric value (or numeric string), and CSS color. Missing labels become Item 1, Item 2 and so on.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>SVG title text; not a separate visible heading.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-description" name="description" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>SVG desc text explaining the data or takeaway.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-ariaLabel" name="ariaLabel" valueType="RefOrValue&lt;string&gt;" defaultValue="title, then Bar chart">
  <p>Accessible name on the SVG image.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-emptyLabel" name="emptyLabel" valueType="RefOrValue&lt;string&gt;" defaultValue="No data">
  <p>Visible fallback when no usable data remains.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-valueSuffix" name="valueSuffix" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Unit appended to formatted values, such as ms or %.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-width" name="width" valueType="RefOrValue&lt;number | string&gt;" defaultValue="100%">
  <p>CSS width. Numeric values become pixel lengths; strings can use CSS units.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-height" name="height" valueType="RefOrValue&lt;number | string&gt;" defaultValue="automatic">
  <p>CSS chart height; omitted height preserves the SVG’s intrinsic aspect ratio.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-minValue" name="minValue" valueType="RefOrValue&lt;number | string&gt;" defaultValue="automatic">
  <p>Requested lower domain bound. The resolved minimum also includes zero and the smallest data value. Omit it to use the data range automatically.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-maxValue" name="maxValue" valueType="RefOrValue&lt;number | string&gt;" defaultValue="automatic">
  <p>Requested upper domain bound. The resolved maximum also includes zero and the largest data value, so bars are never clipped by a tighter bound.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-animated" name="animated" valueType="RefOrValue&lt;boolean | string&gt;" defaultValue="true">
  <p>Enables the SVG entrance animation when bars mount. Bind false for immediate rendering, especially while editing values. This is not an interpolated transition between datasets.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-showValues" name="showValues" valueType="RefOrValue&lt;boolean | string&gt;" defaultValue="true">
  <p>Draws numeric values beside marks. Enable only when labels have enough room.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-showLabels" name="showLabels" valueType="RefOrValue&lt;boolean | string&gt;" defaultValue="true">
  <p>Shows category labels along the horizontal axis.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-showAxis" name="showAxis" valueType="RefOrValue&lt;boolean | string&gt;" defaultValue="true">
  <p>Shows the axis grid and value labels.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="none">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="bar-chart-prop-variantMode" name="variantMode" valueType="RefOrValue&lt;ComponentVariantMode&gt;" defaultValue="stateless">
  <p>Use stateless for content surfaces; stateful enables the treatment’s hover, focus and active styles. It does not add interaction handlers.</p>
</ApiProperty>
