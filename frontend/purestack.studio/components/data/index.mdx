## Pick the right geometry

| Need | Component | What determines the layout |
| --- | --- | --- |
| Compare categories or signed changes | [BarChart](./bar-chart/) | A scale that includes zero and every value |
| Follow an ordered sequence | [LineChart](./line-chart/) | Equally spaced observations across one or more series |
| Show positive parts of a whole | [DoughnutChart](./doughnut-chart/) | Positive values normalized to the total |
| Browse equally sized records | [VirtualList](./virtual-list/) | A known itemHeight |
| Browse wrapping or expandable records | [VariableVirtualList](./variable-virtual-list/) | An initial estimate replaced by measurements |
| Browse a table of equally sized rows | [VirtualTable](./virtual-table/) | A known itemHeight and chosen column layout |
| Browse a table with growing rows | [VariableVirtualTable](./variable-virtual-table/) | Measured row heights and content wrapping |

The chart guides show every tone, variant, and variant mode. The virtualized components expose geometry and rendering props; appearance belongs to the viewport and registered rows. Application search, sorting, data loading, legends, and durable state are composed in the working examples.
