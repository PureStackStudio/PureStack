# Docked navigation

The standard documentation template renders the site's navigation in its sidebar, with the configured appearance and navigation runtime.

On a wide screen, collapse, restore, and resize the sidebar. In this narrow preview, use the header's navigation toggle to open the mobile panel. Expand a group or follow a link to explore the documentation.
