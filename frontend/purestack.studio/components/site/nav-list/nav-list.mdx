NavList exposes no variant or variantMode. Supply row tones, linkClass, ariaCurrent, isOpen, and stable stateKey values in the prepared items.

## Behavior and accessibility

NavList renders a ul. Wrap it in a labelled nav when it is a standalone navigation region. Stable stateKey values identify groups to the navigation runtime. isActive alone does not compute link classes or ariaCurrent; NavMenu performs that preparation.
