## Search states and configuration

The live field above searches the real documentation index. Try a matching term, a term with no matches, then clear it; the results region is separate from the native field. Appearance samples are isolated fields without their own search index.

## Behavior and accessibility

Pagefind indexes the built HTML, so new content appears after a successful indexed build. SearchBox does not fetch application records or replace autocomplete. Keyboard behavior and results are provided by the standard Pagefind search runtime.
