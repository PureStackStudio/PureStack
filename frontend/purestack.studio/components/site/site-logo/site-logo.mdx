## Behavior and accessibility

The logo is a link, not a heading. Give it a useful destination. Letter colors and responsive sizes are resolved when the component is created; these plain string props are not a reactive editor contract. Ensure every chosen color remains readable in each skin.

<ApiProperty anchor="site-logo-prop-brand" name="brand" valueType="string" defaultValue="not set">
  <p>Brand text split into individually styled letters.</p>
</ApiProperty>

<ApiProperty anchor="site-logo-prop-letterColors" name="letterColors" valueType="string" defaultValue="accent fill">
  <p>String of palette indexes for brand letters, for example 00111. The last index repeats for remaining letters; spaces do not advance the color cursor.</p>
</ApiProperty>

<ApiProperty anchor="site-logo-prop-subtitleLetterColors" name="subtitleLetterColors" valueType="string" defaultValue="subtle text fill">
  <p>Palette indexes for subtitle letters, following the same rules as letterColors.</p>
</ApiProperty>

<ApiProperty anchor="site-logo-prop-colors" name="colors" valueType="string[]" defaultValue="not set">

### Composition

<div class="api-contract">
<p>No slots. Register defineLogoComponents and defineIconComponents if an icon is supplied. Without an icon, the glyph uses its built-in mark.</p>
