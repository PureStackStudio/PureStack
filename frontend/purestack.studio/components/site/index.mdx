## What comes from where

| Need | Components | Integration |
| --- | --- | --- |
| Brand identity | SiteLogo, ClassicLogo | Shared logo config, direct props, and responsive sizing |
| Site header | TopBar | Site logo, Pagefind configuration, theme runtime, and optional account access |
| Page hierarchy | NavMenu, NavList | Raw navigation + current URL, or explicitly prepared row state |
| Reading direction | PageLinks, PageToc | SSG neighbors and outline, or explicit destinations and headings |
| Content discovery | SearchBox | Generated Pagefind index and search runtime |
| Appearance preference | ThemeToggle | Theme stylesheets and the theme runtime |
| Account entry | SignIn | Site auth configuration, document account state, and menu runtime |
| Privacy preferences | Consent, SiteFooter | Categories, policy version, services, isolated storage, and the settings target |

Service components depend on the site’s configuration and runtimes. The guides distinguish accepted props from values derived from configuration, and keep isolated examples separate from the real page controls.
