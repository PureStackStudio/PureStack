## Behavior and accessibility

ThemeToggle is a native button labelled “Dark theme”. The theme runtime keeps `aria-pressed` in step with the active theme, so assistive technology announces whether dark is on. The glyphs are decorative and hidden from the accessibility tree.

Each theme stylesheet decides which glyph is visible, so the right one shows on first paint without waiting for script. The turn animates only after the runtime settles the first theme, and it is switched off for visitors who prefer reduced motion.
