## One component model

Write components directly in Regor MDX. PureStack renders the content to HTML, generates its theme styles, and includes the runtime required by components such as Tabs and Modal.

For application state, mount a Regor app from a TypeScript entry point using `RegorApp`. Register the specific component families your app uses, then pass refs and handlers into the template.

## A shared design system

`tone` expresses intent; `variant` defines the visual treatment. Components consume the same semantic palette, typography, and radius tokens. Change the theme to make the system yours.
