## Behavior and accessibility

Focus the summary and press Enter or Space to toggle it. Do not put nested buttons or links inside a summary. The native `toggle` event reports open state; the open prop sets the element state but native user toggling does not write back to a parent ref automatically.

<ApiProperty anchor="expandable-panel-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-description" name="description" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting description for the content.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-meta" name="meta" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Secondary context such as an update time, limitation or reassurance.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-badge" name="badge" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Optional compact label rendered with Badge.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-icon" name="icon" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Registered SVG icon name. In browser apps, include the icon in the resolver passed to defineIconComponents.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-summaryVariant" name="summaryVariant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Independent visual treatment for the stateful summary.</p>
</ApiProperty>

<ApiProperty anchor="expandable-panel-prop-open" name="open" valueType="RefOrValue&lt;boolean&gt;" defaultValue="false">
  <p>Initial or externally bound native details open state. Listen to toggle if application state must track user changes.</p>
</ApiProperty>
