## Usage

Place `TabPane` children inside `Tabs`. Set `selectedTab` to the starting pane’s `id`, give each instance its own `group`, and provide a descriptive `ariaLabel`.

<Panel tone="info" variant="surface">
  <strong>Built in to the publishing pipeline</strong>
  <p>In MDX, <code>Tabs</code> automatically includes PureStack’s tab runtime. The runtime creates responsive controls; native radio inputs handle the static fallback. Your page content is rendered at build time.</p>
</Panel>

## Styling and composition

There are three styling surfaces: `Tabs.variant` for the shell, `Tabs.tabVariant` for the controls, and `TabPane.variant` for individual panels. Pane-level `tone` and `tabVariant` override the inherited values.

The header slot sits above the controls. A disabled pane remains unavailable in both the button row and compact selector.

## Browser state

In a live Regor app, pass a `ref<string>` as `:selectedTab` to share selection with the surrounding UI. Register `defineTabsComponents()` in that app’s component map. After inserting new tabs dynamically, call `window.tsSsgTabs.refresh()` once the markup is mounted.

Static MDX establishes the initial view. Mount a browser app when fields inside the panels need reactive state, validation, or actions. Opening a panel alone does not hydrate the application within it.

## Accessibility

- Give every tab list a descriptive `ariaLabel`.
- Use meaningful tab labels, and use `disabled` for unavailable panels.
- Native radio inputs provide a keyboard-operable fallback without JavaScript.
- Keep unique pane ids so `aria-controls` and `aria-labelledby` remain valid.

## API reference

`TabPane` inherits its group and presentation defaults from the closest `Tabs` context. Use explicit ids and an explicit starting selection for predictable reusable examples.

### Tabs

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `group` | `string` | generated when omitted | Radio group name. Use a different group for each independent Tabs instance. |
| `selectedTab` | `string \| Ref<string>` | first pane visually | Initial pane id, or a shared ref in a live Regor app. Explicitly set the starting pane. |
| `ariaLabel` | `string` | Tabs | Accessible name for the tab list. |
| `tone` | `SemanticTone` | neutral (inherited) | neutral · accent · feature · secondary · custom · ghost · info · success · warning · danger |
| `variant` | `ComponentVariant` | surface | Styles the outer Tabs container. |
| `variantMode` | `'stateful' \| 'stateless'` | stateless | Controls whether the variant includes hover and active styles. |
| `tabVariant` | `ComponentVariant` | underline | Default appearance of the tab controls. |

### TabPane

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `string` | generated when omitted | Document-unique id. Also forms the radio id, label id, and panel id. |
| `label` | `string` | id | Visible title of the tab. |
| `icon` | `string` | — | Optional registered icon before the label. |
| `disabled` | `boolean` | false | Disables the radio, generated tab button, and compact select option. |
| `group` | `string` | parent Tabs.group | Inherits the radio group from the nearest Tabs context. |
| `tone` | `SemanticTone` | parent Tabs.tone | Overrides the parent tone for this pane and its control. |
| `variant` | `ComponentVariant` | none | Styles this pane’s content surface. |
| `variantMode` | `'stateful' \| 'stateless'` | parent Tabs.variantMode | State behavior of this pane’s variant. |
| `tabVariant` | `ComponentVariant` | parent, then underline | Overrides the parent control variant for this pane. |

### Slots and runtime

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `Tabs.default` | `slot` | — | TabPane children. |
| `Tabs.header` | `named slot` | — | Content before the tab list. |
| `TabPane.default` | `slot` | — | The pane’s content; stays in the DOM when another pane is selected. |
| `window.tsSsgTabs.refresh(target?)` | `(selector?: string) => void` | automatic at load | Rebuilds runtime controls after dynamically adding or removing tabs. |
