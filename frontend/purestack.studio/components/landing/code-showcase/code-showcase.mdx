## Feature map

| Public feature | Visible example |
| --- | --- |
| tone, variant | Complete galleries above, with all supported values visible together. |
| eyebrow, title, summary | The original code-and-result example introduces the purpose of the snippet. |
| language | MDX and TypeScript badges label the snippets; the title-only result sample omits the language badge. |
| resultTitle, resultMeta | Compare code-only, title-only result, metadata-only result, and the original result with both fields. |
| Default and result slots | The default slot holds code; the named result slot holds live rendered content. A result heading or metadata is required to show that panel. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone and variant, but no variantMode. Style individual child components explicitly when their appearance should match.

## Behavior and accessibility

The language prop is a badge, not a syntax-highlighting engine. ts-ssg highlights fenced code in MDX automatically. A result slot is rendered only when resultTitle or resultMeta is present. Keep results keyboard-accessible when they contain controls.

<ApiProperty anchor="code-showcase-prop-eyebrow" name="eyebrow" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Short context above the heading, such as a category or release label.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-summary" name="summary" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>A concise explanation beneath the heading.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-language" name="language" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Language label displayed in a Badge. It does not transform source text.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-resultTitle" name="resultTitle" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Result heading. Setting this or resultMeta enables the result panel.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-resultMeta" name="resultMeta" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Result status or metadata badge. Setting this or resultTitle enables the result panel.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="code-showcase-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>
