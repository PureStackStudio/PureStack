## A workspace snapshot

MetricStrip brings related MetricItems together on one surface, with generous
spacing and a consistent reading order. Use it to introduce a product's key
numbers or give a quick view of a project's progress.

The default layout moves from one column on narrow screens to two at `sm` and
four at `lg`. These illustrative values show a complete workspace snapshot.

## Feature map

| Public feature | Visible example |
| --- | --- |
| tone, variant | Complete galleries above, with all supported values visible together. |
| columns, columnsSm, columnsLg | Two-, three-, and four-metric examples each start with one column and change at the small and large breakpoints. Resize to compare. |
| Default slot | MetricItem supplies the usual child; the strip can group other content too. Child tones are explicit. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone and variant, but no variantMode. Style individual child components explicitly when their appearance should match.

## Behavior and accessibility

Use short labels and include units, time periods, and sources in the details.
The label, value, and detail inherit the strip's text color; each MetricItem's
tone colors its icon. MetricStrip groups content and does not calculate values.

The strip uses Panel, Grid, and built-in spacing utilities, with no additional
component stylesheet. Use its `metric-strip` class for any site-specific styling.

<ApiProperty
  anchor="metric-strip-prop-tone"
  name="tone"
  valueType="RefOrValue&lt;SemanticTone&gt;"
  defaultValue="inherited"
>
  <p>
    Semantic intent: neutral, accent, secondary, info, success, warning, danger,
    feature, custom or ghost. The active skin supplies the colors.
  </p>
</ApiProperty>

<ApiProperty
  anchor="metric-strip-prop-variant"
  name="variant"
  valueType="RefOrValue&lt;ComponentVariant&gt;"
  defaultValue="surface"
>
  <p>
    Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass,
    flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link,
    sheen, underline, rail, bracket or none.
  </p>
</ApiProperty>

<ApiProperty
  anchor="metric-strip-prop-columns"
  name="columns"
  valueType="RefOrValue&lt;number | string&gt;"
  defaultValue="1"
>
  <p>
    Column count from 1 to 12, or a CSS track list such as minmax(0, 1fr) auto.
    Numeric counts are clamped.
  </p>
</ApiProperty>

<ApiProperty
  anchor="metric-strip-prop-columnsSm"
  name="columnsSm"
  valueType="RefOrValue&lt;number | string&gt;"
  defaultValue="2"
>
  <p>Column count or CSS track list at the theme’s sm breakpoint and above.</p>
</ApiProperty>

<ApiProperty
  anchor="metric-strip-prop-columnsLg"
  name="columnsLg"
  valueType="RefOrValue&lt;number | string&gt;"
  defaultValue="4"
>
  <p>Column count or CSS track list at the theme’s lg breakpoint and above.</p>
</ApiProperty>
