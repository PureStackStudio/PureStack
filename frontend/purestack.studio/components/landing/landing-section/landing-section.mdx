# Landing<wbr/>Section

Introduce a section and arrange its content beside a clear heading at larger breakpoints.

<Badge tone="accent" variant="surface">LandingSection</Badge>

[View source](https://github.com/PureStackStudio/PureStack/blob/main/packages/ts-components/src/standard/landing/landingTypes.ts) · [API reference](#api-reference)



## Heading and feature

The heading counts as a grid item. At lg, it shares the row with the feature card.

## Behavior and accessibility

Use titleTag to fit the heading into the document. The base layout is always one column. Both columns and columnsLg configure the large-screen layout, with columnsLg taking precedence.

<ApiProperty anchor="landing-section-prop-eyebrow" name="eyebrow" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Short context above the heading, such as a category or release label.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-subtitle" name="subtitle" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting text beneath the title.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-titleTag" name="titleTag" valueType="RefOrValue&lt;LandingTitleTag&gt;" defaultValue="h2">
  <p>Heading element. Accepts h1–h6, p, div or span; invalid values fall back to h2. Match the surrounding document hierarchy.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="none">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-variantMode" name="variantMode" valueType="RefOrValue&lt;ComponentVariantMode&gt;" defaultValue="stateless">
  <p>Use stateless for content surfaces; stateful enables the treatment’s hover, focus and active styles. It does not add interaction handlers.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-columns" name="columns" valueType="RefOrValue&lt;number | string&gt;" defaultValue="not set">
  <p>Fallback large-breakpoint column definition. Base columns remain 1.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-columnsLg" name="columnsLg" valueType="RefOrValue&lt;number | string&gt;" defaultValue="columns, then 1">
  <p>Large-breakpoint column definition. Includes the optional SectionHeader as a grid item.</p>
</ApiProperty>

<ApiProperty anchor="landing-section-prop-alignItems" name="alignItems" valueType="RefOrValue&lt;GridAlignItems&gt;" defaultValue="start">
  <p>Grid alignment: stretch, start, center or end.</p>
</ApiProperty>
