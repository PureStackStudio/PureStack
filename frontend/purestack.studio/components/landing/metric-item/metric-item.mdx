## Behavior and accessibility

The value is text, so units and formatted numbers remain under your control. Tone affects the optional icon frame; it does not imply a trend or change the value’s meaning.

<ApiProperty anchor="metric-item-prop-label" name="label" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible label. Use language that describes the control or value in its surrounding context.</p>
</ApiProperty>

<ApiProperty anchor="metric-item-prop-value" name="value" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Displayed value as text, including any unit or formatting.</p>
</ApiProperty>

<ApiProperty anchor="metric-item-prop-detail" name="detail" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting explanation below the value.</p>
</ApiProperty>

<ApiProperty anchor="metric-item-prop-icon" name="icon" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Registered SVG icon name. In browser apps, include the icon in the resolver passed to defineIconComponents.</p>
</ApiProperty>

<ApiProperty anchor="metric-item-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>
