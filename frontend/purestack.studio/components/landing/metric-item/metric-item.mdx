## A value with context

MetricItem puts the value first visually, with a label above it and supporting
detail below. Use it for a product statistic, a project snapshot, or a short
status. An optional icon helps readers recognize the subject at a glance.

Include units, time periods, or the source of a measurement in the content.
These illustrative examples show two different kinds of value inside Panel.

## Feature map

| Public feature | Visible example |
| --- | --- |
| tone | Complete galleries above, with all supported values visible together. |
| label, value, detail | Compare the minimal number, a labelled value, and a formatted percentage. value is display text. |
| icon | The percentage and rich-content examples add an icon; the minimal and labelled examples omit it. |
| Default slot | Rich default slot adds a status badge and extra supporting text. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone but no variant or variantMode. Its icon uses a fixed surface treatment.

## Behavior and accessibility

The value is text, so units and formatted numbers remain under your control.
Labels and details explain what it means; the icon is decorative. Tone affects
the optional icon frame and does not imply a trend or change the value's meaning.

MetricItem uses existing typography and layout utilities and adds no custom
stylesheet. It has no background of its own: use it directly, place it inside
Panel, or group related items in MetricStrip.
