## Choose by purpose

| Purpose | Components | Composition |
| --- | --- | --- |
| Establish rhythm | LandingBand, LandingSection | Decorative backdrop and accessible section headings |
| Explain value | FeatureCard, CodeShowcase | Story, default content, and named action or result slots |
| Provide evidence | MetricStrip, MetricItem | Responsive grouping and formatted display values |
| Compare choices | ComparisonTable, ComparisonColumn, ComparisonFeature | A card grid with native feature lists |
| Present an offer | PricingTable, PricingPlan, PricingFeature | Plan headings, price text, explicit limits, and navigation |
| Invite a next step | CtaSection | Primary, secondary, and custom actions |

Containers do not provide billing, entitlement checks, data fetching, or analytics. Your application owns those behaviors. LandingBand is decorative; put interactive content in the other compositions.
