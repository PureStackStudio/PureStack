## Feature map

| Public feature | Visible example |
| --- | --- |
| variant, variantMode, tone | Complete galleries above, with all supported values visible together. |
| title, summary | Compare the free plan, custom plan, and capabilities card. |
| price, period | Free, monthly, custom, and omitted prices are visible together. Period appears only alongside a price. |
| icon, badge | The complete original card includes both; custom price is badge-only and the capabilities card is icon-only. |
| note | The free and rich-feature plans clarify billing context and limits below their features. |
| ctaLabel, ctaLink | Free and team plans navigate to real guides. Custom and capabilities cards omit the CTA; both props are needed to render it. |
| Default slot | PricingFeature children form a native list, with simple and rich detail examples. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

## Behavior and accessibility

Use clear billing text and disclose relevant limits alongside the price. A CTA is rendered only when both ctaLabel and ctaLink are set. There is no checkout behavior built into the component.
