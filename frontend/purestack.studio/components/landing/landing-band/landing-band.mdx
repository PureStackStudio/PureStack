# Landing<wbr/>Band

A full-width visual band with shaped edges, background imagery and theme-aware surfaces.

<Badge tone="accent" variant="surface">LandingBand</Badge>

[View source](https://github.com/PureStackStudio/PureStack/blob/main/packages/ts-components/src/standard/landing/landingTypes.ts) · [API reference](#api-reference)

LandingBand extends to the viewport edges, including within a documentation layout. Its content is decorative by default: the band sets pointer-events to none.

## A shaped section boundary

The bottom edge creates a transition into the next section. Keep the important copy away from the clipped edge.

## Behavior and accessibility

Use backgrounds as decoration and keep meaningful image content in a normal image element with alt text. Edge clipping needs enough padding. The full-width bleed is intentional; avoid placing a band in a narrow card. Interactive children must explicitly opt back into pointer events.

<ApiProperty anchor="landing-band-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surfaceAlt">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-variantMode" name="variantMode" valueType="RefOrValue&lt;ComponentVariantMode&gt;" defaultValue="stateless">
  <p>Use stateless for content surfaces; stateful enables the treatment’s hover, focus and active styles. It does not add interaction handlers.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-image" name="image" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Background image URL. It becomes a CSS background and has no accessible alternative text.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-imageFit" name="imageFit" valueType="RefOrValue&lt;LandingBandImageFit&gt;" defaultValue="cover">
  <p>Background sizing value: cover, contain, fill, none or scale-down are accepted by the type; CSS background-size reliably supports cover, contain and valid CSS sizes.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-imagePosition" name="imagePosition" valueType="RefOrValue&lt;string&gt;" defaultValue="center">
  <p>CSS background-position value, such as center or center top.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-display" name="display" valueType="RefOrValue&lt;CSSProps['display']&gt;" defaultValue="flex">
  <p>CSS display mode for the section.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-alignItems" name="alignItems" valueType="RefOrValue&lt;CSSProps['alignItems']&gt;" defaultValue="start">
  <p>CSS align-items for the band’s content.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-justifyContent" name="justifyContent" valueType="RefOrValue&lt;CSSProps['justifyContent']&gt;" defaultValue="center">
  <p>CSS justify-content for the band’s content.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-height" name="height" valueType="RefOrValue&lt;string&gt;" defaultValue="16rem">
  <p>CSS minimum height, not a fixed height. Content can make the band taller.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-marginTop" name="marginTop" valueType="RefOrValue&lt;string&gt;" defaultValue="0">
  <p>CSS top margin.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-marginBottom" name="marginBottom" valueType="RefOrValue&lt;string&gt;" defaultValue="0">
  <p>CSS bottom margin.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-paddingTop" name="paddingTop" valueType="RefOrValue&lt;string&gt;" defaultValue="1em">
  <p>Top padding; a slanted top edge adds edgeSize automatically.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-paddingBottom" name="paddingBottom" valueType="RefOrValue&lt;string&gt;" defaultValue="1em">
  <p>Bottom padding; a slanted bottom edge adds edgeSize automatically.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-topEdge" name="topEdge" valueType="RefOrValue&lt;LandingBandEdge&gt;" defaultValue="flat">
  <p>Top clipping edge: flat, slant-up or slant-down.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-bottomEdge" name="bottomEdge" valueType="RefOrValue&lt;LandingBandEdge&gt;" defaultValue="flat">
  <p>Bottom clipping edge: flat, slant-up or slant-down.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-edgeSize" name="edgeSize" valueType="RefOrValue&lt;string&gt;" defaultValue="4rem">
  <p>Vertical depth of the slant, expressed as a CSS length.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-topEdgeStart" name="topEdgeStart" valueType="RefOrValue&lt;string&gt;" defaultValue="0%">
  <p>Horizontal start of the top diagonal as a CSS length or percentage.</p>
</ApiProperty>

<ApiProperty anchor="landing-band-prop-bottomEdgeStart" name="bottomEdgeStart" valueType="RefOrValue&lt;string&gt;" defaultValue="0%">
  <p>Horizontal start of the bottom diagonal as a CSS length or percentage.</p>
</ApiProperty>
