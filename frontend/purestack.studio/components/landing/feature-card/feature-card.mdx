## A feature with a next step

FeatureCard gives one capability a clear introduction: an icon and optional
badge, a short heading, and a readable explanation. Content follows a consistent
start alignment, with room between each part of the story.

Use the `actions` slot for a next step. Cards stretch to fill their grid row,
keeping actions aligned even when one card has more content than another.

## Feature map

| Public feature | Visible example |
| --- | --- |
| tone, variant | Complete galleries above, with all supported values visible together. |
| eyebrow, title, summary | Compare the text-only card and the complete workflow card. |
| icon, badge | Icon-only, badge-only, and combined decoration are visible together. |
| Default slot | The complete workflow card adds rich supporting text below the summary. |
| actions slot | Actions sit at the bottom of equal-height cards. Compare one destination with two destinations in Both slots. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone and variant, but no variantMode. Style individual child components explicitly when their appearance should match.

## Behavior and accessibility

The generated title is h3. Place feature cards under an h2 section heading. The
icon is decorative; the heading and summary describe the feature. The card is
a content container, and links or buttons in `actions` provide interaction.

FeatureCard uses built-in layout, spacing, and typography utilities and adds no
component-specific stylesheet. Use its `feature-card` class for any additional
styling your site needs.
