## Feature map

| Public feature | Visible example |
| --- | --- |
| tone, variant | Complete galleries above, with all supported values visible together. |
| eyebrow, title, summary | Compare the text-only card and the complete workflow card. |
| icon, badge | Icon-only, badge-only, and combined decoration are visible together. |
| Default slot | The complete workflow card adds rich supporting text below the summary. |
| actions slot | Compare one destination in the original example with two destinations in Both slots. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone and variant, but no variantMode. Style individual child components explicitly when their appearance should match.

## Behavior and accessibility

The generated title is h3. Place feature cards under an h2 section heading, and keep summaries comparable in length. An icon and a badge support the title; they should not carry the only explanation.

<ApiProperty anchor="feature-card-prop-eyebrow" name="eyebrow" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Short context above the heading, such as a category or release label.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-summary" name="summary" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>A concise explanation beneath the heading.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-badge" name="badge" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Optional compact label rendered with Badge.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-icon" name="icon" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Registered SVG icon name. In browser apps, include the icon in the resolver passed to defineIconComponents.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="feature-card-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>
