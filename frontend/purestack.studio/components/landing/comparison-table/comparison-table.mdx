## Behavior and accessibility

The component renders a section with a grid. If readers need row-by-row relationships across many values, use an HTML table instead. Column titles are h3 beneath the optional h2 section title.

<ApiProperty anchor="comparison-table-prop-eyebrow" name="eyebrow" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Short context above the heading, such as a category or release label.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-title" name="title" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible heading. Choose a short title that identifies the content or task.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-subtitle" name="subtitle" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting text beneath the title.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-columns" name="columns" valueType="RefOrValue&lt;number | string&gt;" defaultValue="1">
  <p>Column count from 1 to 12, or a CSS track list such as minmax(0, 1fr) auto. Numeric counts are clamped.</p>
</ApiProperty>

<ApiProperty anchor="comparison-table-prop-columnsLg" name="columnsLg" valueType="RefOrValue&lt;number | string&gt;" defaultValue="3">
  <p>Column count or CSS track list at the theme’s lg breakpoint and above.</p>
</ApiProperty>
