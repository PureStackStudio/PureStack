## Feature map

| Public feature | Visible example |
| --- | --- |
| tone | Complete galleries above, with all supported values visible together. |
| icon | Compare the default lucide:check and an explicit iconoir:check. |
| Default slot | Rich detail combines a strong label, supporting text, and a real guide link. Keep the li inside a list. |
| Native attributes and events | Pass attributes through the root; keyboard behavior belongs to the composed native controls. |

This component exposes tone but no variant or variantMode. Its icon uses a fixed surface treatment.

## Behavior and accessibility

Use explicit text for included, limited or unavailable features. An icon color alone does not communicate availability to every reader.
