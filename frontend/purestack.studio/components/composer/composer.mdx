## Behavior and accessibility

The toolbar supports bold, italic, underline, alignment, lists, links, clear formatting and HTML source. Formatting uses browser editing commands; select the target text first. Pasted and edited markup is normalized by the email HTML policy. Validate content at your application boundary before storing or sending it. The editor is a multiline textbox with a name from label or placeholder.

### Composition

<div class="api-contract">
<p>No slots. Register defineComposerComponents and every toolbar icon through defineIconComponents. The html and text refs are the data contract; the component does not submit a form or upload attachments.</p>
</div>

### Inline images and attachments

The editor preserves supported email markup and normalizes links, styles and image URLs. Use `imagePreviewUrls` when an email model references `cid:` images. Manage the corresponding attachments and object-URL cleanup in the owning app. `createComposerBodyHtml` wraps content in the package’s email body presentation.
