## Two apps, independent state

Both mounts load the same module URL. Browser modules execute once per URL; the entry point explicitly creates an app for every matching mount. Each call gets fresh refs and unique field IDs. Completing a task in one review leaves the other unchanged.

## Explicit source ownership

Bind an explicit sourceRelPath to change the source directory used to resolve src. The colon binding overrides the source owner automatically attached by MDX compilation. Here the owner is the real PageScript guide, and its sibling-relative src resolves back to this guide’s playground. The emitted bundle is shared with the other mounts.

<ComponentExample label="A mount with a different source owner" caption="The app is still mounted on this page. sourceRelPath affects build-time path resolution, not DOM selection.">

## Feature map

| Feature | Visible example |
| --- | --- |
| src | The focused app loads a colocated TypeScript entry point. |
| sourceRelPath | Shared source review resolves src relative to another real MDX owner. |
| Native id and data attributes | Every mount has its own ID and review label; the entry reads those attributes. |
| Browser registration | The full source registers each component family used by the template. |
| Independent state | Design and content reviews update and reset independently. |
| Reactive values and events | Edit the goal and note, complete or undo a task, and pause changes. |
| Derived presentation | Status, progress, disabled buttons, and the note reflect the current refs. |

RegorApp has no tone, variant, or variantMode props and no server-rendered content slot. Appearance belongs to the components inside the mounted app. It creates a browser app rather than hydrating a server-rendered Regor component tree.

## Behavior and accessibility

RegorApp renders an app mount element and a module entry script. Give the mount a unique native id and use the matching selector in createApp. Source resolution is automatic; sourceRelPath is only an override. Register the component families and SVG icons your browser app uses.
