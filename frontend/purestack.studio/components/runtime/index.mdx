# Browser entry points

<p class="component-directory-lead">Small behavior. Clear ownership. A page that stays understandable.</p>

Choose an independent component app or enhance the HTML already on the page. Both entry points resolve colocated TypeScript through the SSG; your browser code decides what happens next.

## Compare responsibilities

| Need | RegorApp | PageScript |
| --- | --- | --- |
| Visible root | An app mount element | A script element |
| UI ownership | Browser template and registered components | Existing HTML, selected by your script |
| State | Refs and computed values in each createApp context | Your chosen DOM or JavaScript state |
| Initialization | Entry point explicitly calls createApp | Entry point runs its enhancement code |
| Multiple instances | Create one app with fresh state per mount | Scope queries and listeners to each region |
| Source resolution | src and optional sourceRelPath | src and optional sourceRelPath |
| Script placement and metadata | Uses the internal default PageScript | teleport, type, loading flags, and native metadata |
| Appearance | Components inside the app | Enhanced HTML and its components |
