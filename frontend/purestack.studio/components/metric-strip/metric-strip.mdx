## Behavior and accessibility

Use labels and details to communicate units, periods and provenance. MetricStrip does not calculate values; your data or application owns them.

## API reference

<div class="api-overview">
  <p class="text-eyebrow">MetricStrip contract</p>
  <p>Props below are the public template API. RefOrValue accepts a literal or a reactive ref; bind refs with a colon-prefixed attribute. Native attributes and events can be passed through the component root.</p>
</div>

<ApiProperty anchor="metric-strip-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="metric-strip-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surface">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="metric-strip-prop-columns" name="columns" valueType="RefOrValue&lt;number | string&gt;" defaultValue="1">
  <p>Column count from 1 to 12, or a CSS track list such as minmax(0, 1fr) auto. Numeric counts are clamped.</p>
</ApiProperty>

<ApiProperty anchor="metric-strip-prop-columnsSm" name="columnsSm" valueType="RefOrValue&lt;number | string&gt;" defaultValue="2">
  <p>Column count or CSS track list at the theme’s sm breakpoint and above.</p>
</ApiProperty>

<ApiProperty anchor="metric-strip-prop-columnsLg" name="columnsLg" valueType="RefOrValue&lt;number | string&gt;" defaultValue="4">
  <p>Column count or CSS track list at the theme’s lg breakpoint and above.</p>
</ApiProperty>
