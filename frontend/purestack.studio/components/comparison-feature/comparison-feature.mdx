## Behavior and accessibility

Use explicit text for included, limited or unavailable features. An icon color alone does not communicate availability to every reader.

<ApiProperty anchor="comparison-feature-prop-icon" name="icon" valueType="RefOrValue&lt;string&gt;" defaultValue="lucide:check">
  <p>Registered icon name. The default check is decorative support for the feature text.</p>

<ApiProperty anchor="comparison-feature-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>
