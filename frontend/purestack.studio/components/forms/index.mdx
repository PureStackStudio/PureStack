# Forms and input

<p class="component-directory-lead">Make every field feel like a clear next step.</p>

Help people enter a value, make a choice, and understand the result. Sixteen components cover native fields, searchable suggestions, rich text, local files, and the supporting pieces of a complete form. Every guide includes working examples and its complete public API.

## Pick the right input

| Need | Components |
| --- | --- |
| Collect a native value | [FormInputField](./form-input-field/) |
| Choose from a known list | [FormSelectField](./form-select-field/) or [AutoCompleteInput](./auto-complete-input/) |
| Make a boolean choice | [FormCheck](./form-check/) |
| Choose several values | [MultiAutoCompleteInput](./multi-auto-complete-input/) |
| Customize suggestion labels | [AutoCompleteOptionRow](./auto-complete-option-row/) and [MultiAutoCompleteOptionRow](./multi-auto-complete-option-row/) |
| Compose rich text | [Composer](./composer/) |
| Collect local files | [DropFiles](./drop-files/) |
| Compose and submit a form | [AppForm](./app-form/) and [FormSubmit](./form-submit/) |
| Add help, structure, and feedback | [FormMeta](./form-meta/), [FormAssistLink](./form-assist-link/), [FormDivider](./form-divider/), [FormStatus](./form-status/) |
| Start with a contact flow | [ContactForm](./contact-form/) |
