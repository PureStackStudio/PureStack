## Token and suggestion features

| Feature | How to try it |
| --- | --- |
| Selected items and query | Existing tags remain visible while the query changes. |
| Custom values and duplicates | Toggle both controls in the live example, then enter the same new tag twice. |
| Separators | Comma and semicolon commit tokens. Enter also creates a token when allowed. |
| Protected and invalid tokens | The existing state example shows a non-removable required item and an invalid item. |
| Item tone | Each selected item can choose its own semantic palette. |
| Keywords and disabled options | Search typed to find TypeScript; the unavailable suggestion cannot be chosen. |
| Loading, empty, minLength, maxResults, openOnFocus | Inspect the appearance and live search controls separately. |
| Structured values | Suggestion values may be strings or numbers; missing values fall back to labels. |
| Custom row | rowComponent changes suggestion presentation without replacing the parent’s selection logic. |
| Callback transforms | onCreateItem, onOptionToItem, and onSplitInput customize creation, mapping, and splitting. |
| Notifications | itemschange, itemremove, itemcreate, optionselect, and querychange report browser actions. |

```html
<MultiAutoCompleteInput id="release-tags" label="Tags" name="tags"
  :items="tags" :model="query" :options="suggestions"
  :allowCustomValues="true" :allowDuplicates="false" separators=",;"
  minLength="1" maxResults="4" :openOnFocus="true"
  :onCreateItem="createTag" :onOptionToItem="mapSuggestion" :onSplitInput="splitTags"
  :onItemsChange="itemsChanged" :onSelect="selected" :onSearch="searched"
  @itemremove="removed" @itemcreate="created" @querychange="queryChanged"/>
```

## Behavior and accessibility

Arrow keys and Enter select suggestions; Escape closes the popup. Backspace on an empty query removes the last removable token. Each selected item produces a hidden field when name is supplied. required applies to the query input, so validate selected items explicitly when requiring at least one token.

### Composition

<div class="api-contract">
<p>No slots. Register defineMultiAutoCompleteInputComponents and defineIconComponents. Use sref for items and ref for the current text model.</p>
</div>

### Events and item data

The input emits `itemschange`, `itemremove`, `itemcreate`, `optionselect` and `querychange`. Each item can carry `label`, `value`, `disabled`, `invalid`, `tone` and `keywords`. Keep persistence and domain validation in the owning app.
