## Destinations and browsing context

href, label, target, and rel make the complete public API. A missing href omits the anchor. External GitHub links explicitly open a new tab.

## Behavior and accessibility

An empty destination suppresses the link. Link text comes from label, not a slot. Internal URLs are base-path aware in SSG context.

## API reference

<div class="api-overview">
  <p class="text-eyebrow">FormAssistLink contract</p>
  <p>Props below are the public template API. RefOrValue accepts a literal or a reactive ref; bind refs with a colon-prefixed attribute. Native attributes and events can be passed through the component root.</p>
</div>

<ApiProperty anchor="form-assist-link-prop-href" name="href" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Navigation destination. Internal paths are resolved against the site base path when SSG context is available.</p>
</ApiProperty>

<ApiProperty anchor="form-assist-link-prop-label" name="label" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible label. Use language that describes the control or value in its surrounding context.</p>
</ApiProperty>

<ApiProperty anchor="form-assist-link-prop-target" name="target" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Native browsing target. _blank opens a new browsing context.</p>
</ApiProperty>

<ApiProperty anchor="form-assist-link-prop-rel" name="rel" valueType="RefOrValue&lt;string&gt;" defaultValue="automatic for _blank">
  <p>Native link relationship. An explicit value replaces the automatic noopener noreferrer used for _blank.</p>
</ApiProperty>
