## Composition, validation, and submission

| Feature | Visible example |
| --- | --- |
| action and method | Native endpoint attributes; the local example intercepts submit. |
| Default slot | Inputs, metadata, help links, divider, and feedback can be composed freely. |
| Validation | AppForm uses novalidate. Call reportValidity in your submit handler when you want native validation. |
| Form data | Give each contributing field a name, then read new FormData(form). |
| Reset | The live example resets its refs explicitly; resetting a native form alone does not define application state. |
| Appearance | Every tone and variant is visible above. |

```html
<AppForm action="/api/projects" method="post" @submit.prevent="save">
  <FormInputField id="project-name" name="project" label="Project name" :model="projectName" :required="true"/>
  <FormMeta><FormSubmit label="Save project" tone="accent"/><FormAssistLink href="/guides/" label="Need help?"/></FormMeta>
  <FormStatus :hidden="!message">{{ message }}</FormStatus>
</AppForm>
```

## Behavior and accessibility

AppForm always renders `novalidate`. Use reportValidity or your own validation in a submit handler. Named controls participate in FormData; disabled controls do not. Reset reactive refs explicitly when handling reset in a Regor app.

<ApiProperty anchor="app-form-prop-action" name="action" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Native submission URL, resolved against the SSG base path. Browser examples intercept submit to keep data local.</p>
</ApiProperty>

<ApiProperty anchor="app-form-prop-method" name="method" valueType="RefOrValue&lt;string&gt;" defaultValue="browser default: get">
  <p>Native form method. Set post when your endpoint expects a request body.</p>
</ApiProperty>

<ApiProperty anchor="app-form-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="app-form-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="none">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>
