## Search and selection features

| Feature | How to try it |
| --- | --- |
| Query and selected value | Type a keyword such as Frankfurt; the result label and selected value remain distinct. |
| Disabled suggestions | Private region is visible but cannot be selected. |
| Loading and empty messages | Toggle loading, or search for a value with no matches. |
| Minimum query length | minLength controls when filtering opens; adjust it in the live demo. |
| Result limit | maxResults caps the list; adjust it in the live demo. |
| Open on focus | Toggle it, then focus the input with an empty query. |
| Custom row | The existing custom-row example includes its component and registration. |
| Callbacks and events | onSearch and onSelect callbacks, plus querychange and optionselect events, carry the query or resolved option. |
| Field semantics | type, name, required, autocomplete, placeholder, disabled, and both icon positions follow FormInputField. |

```html
<AutoCompleteInput id="region-search" label="Region" name="region"
  :model="query" :selectedValue="selectedRegion" :options="regions"
  minLength="2" maxResults="3" :openOnFocus="false"
  loadingText="Finding regions…" emptyText="No matching region"
  :context="{ onSearch: search, onSelect: select }" @querychange="queryChanged" @optionselect="optionSelected"/>
```

## Behavior and accessibility

Arrow keys move through enabled suggestions; Enter selects, Escape closes. Search matches labels, values and keywords case-insensitively. Editing the query can clear selectedValue. Query text alone is not proof that an option was selected. Keep custom rows free of nested interactive controls.

### Composition

<div class="api-contract">
<p>No slots. Register defineAutoCompleteInputComponents, defineFormInputField and defineIconComponents. Custom rows are registered under the name passed to rowComponent.</p>
</div>

### Option and event contracts

```typescript
interface AutoCompleteOption {
  label: RefOrValue<string>
  value?: RefOrValue<string | number>
  disabled?: RefOrValue<boolean>
  keywords?: RefOrValue<string | string[]>
}
```

The component also emits `optionselect` and `querychange`. Use callbacks or emitted events for application integration; avoid processing the same change through both paths.
