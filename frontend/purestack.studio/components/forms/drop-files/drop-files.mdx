## File collection features

| Feature | How to try it |
| --- | --- |
| Picker, drop, paste | All three add local File objects to the same selection. |
| accept | The main demo accepts text, images, and PDF; filtering applies to every entry path. |
| multiple | Toggle multiple files; single mode retains one accepted selection. |
| disabled | Lock the collector; adding and removal are unavailable. |
| File metadata | Each item includes id, file, name, type, size, formatted size, lastModified, and icon. |
| Remove and clear | Remove individual files with their button, or clear the demo list. |
| Empty copy | label, hint, emptyTitle, and emptyText describe the collector before files are added. |
| Icons | uploadIcon, fileIcon, removeIcon, and iconMap choose registered symbols. |
| onChange | Receives the updated selection; this component does not upload files. |

```html
<DropFiles label="Reference files" hint="Images and PDF only"
  emptyTitle="Add your references" emptyText="Choose files, drop them, or paste."
  accept="image/*,.pdf" :multiple="true" :disabled="locked" :files="files"
  uploadIcon="lucide:cloud-upload" fileIcon="lucide:file" removeIcon="lucide:trash-2"
  :iconMap="fileIcons" :context="{ onChange: filesChanged }"/>
```

## Behavior and accessibility

The drop zone opens the native picker with Enter or Space. File acceptance is a client-side convenience, not server validation. Duplicates are identified from file metadata. onChange runs when the component changes the selection; assigning the files ref yourself is application state management.

<ApiProperty anchor="drop-files-prop-files" name="files" valueType="SRef&lt;DropFileItem[]&gt;" defaultValue="sref([])">
  <p>Writable shallow ref of DropFileItem[]. Each item retains its File plus id, name, type, size, sizeLabel, lastModified and icon.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-accept" name="accept" valueType="RefOrValue&lt;string&gt; | string[]" defaultValue="all files, or iconMap keys">
  <p>Comma-separated MIME types, wildcards or extensions; arrays are also accepted. An explicit accept list takes precedence over iconMap keys.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-iconMap" name="iconMap" valueType="DropFilesIconMap | SRef&lt;DropFilesIconMap&gt;" defaultValue="built-in type icons">
  <p>MIME/extension-to-icon map merged with the defaults. When accept is omitted, a supplied map also determines accepted types.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-label" name="label" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Visible label. Use language that describes the control or value in its surrounding context.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-hint" name="hint" valueType="RefOrValue&lt;string&gt;" defaultValue="not set">
  <p>Supporting text beneath the drop-zone instructions.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-emptyTitle" name="emptyTitle" valueType="RefOrValue&lt;string&gt;" defaultValue="Add files">
  <p>Drop-zone heading, shown even when files are selected.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-emptyText" name="emptyText" valueType="RefOrValue&lt;string&gt;" defaultValue="Click, tap, paste, or drag files here.">
  <p>Drop-zone instructions.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-disabled" name="disabled" valueType="RefOrValue&lt;boolean&gt;" defaultValue="false">
  <p>Disables interaction. Use a bound boolean, for example :disabled="isLocked".</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-multiple" name="multiple" valueType="RefOrValue&lt;boolean&gt;" defaultValue="true">
  <p>false accepts the first matching file and replaces the current list.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-tone" name="tone" valueType="RefOrValue&lt;SemanticTone&gt;" defaultValue="inherited">
  <p>Semantic intent: neutral, accent, secondary, info, success, warning, danger, feature, custom or ghost. The active skin supplies the colors.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-variant" name="variant" valueType="RefOrValue&lt;ComponentVariant&gt;" defaultValue="surfaceAlt">
  <p>Visual treatment. Accepts solid, surface, surfaceAlt, spotlight, glass, flat, flatAlt, flatSolid, outlineFill, outline, subtle, subtleBtn, link, sheen, underline, rail, bracket or none.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-uploadIcon" name="uploadIcon" valueType="RefOrValue&lt;string&gt;" defaultValue="lucide:cloud-upload">
  <p>Drop-zone icon.</p>
</ApiProperty>

<ApiProperty anchor="drop-files-prop-fileIcon" name="fileIcon" valueType="RefOrValue&lt;string&gt;" defaultValue="lucide:file">
  <p>Fallback file icon when no type-specific mapping matches.</p>

<ApiProperty anchor="drop-files-prop-removeIcon" name="removeIcon" valueType="RefOrValue&lt;string&gt;" defaultValue="lucide:trash-2">
