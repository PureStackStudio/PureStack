# ts-ssg

Minimal static site generator using PureStack HTML/CSS with MD/MDX support.

## Quick start (test drive)
From repo root:

```bash
yarn dev
```

Output will be written to:
`packages/ts-ssg/dist/site`

Open `packages/ts-ssg/dist/site/index.html` in a browser.

## Customize content
Edit files under:
`packages/ts-ssg/sample-content`

Supported extensions: `.md`, `.mdx`

Frontmatter `title` is used as the page title.
