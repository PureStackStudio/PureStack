# Content links

The markdown compiler rewrites links to `.md`, `.mdx`, and `.rmdx` files into public
routes. In an i18n site, the current source locale is part of that decision.

| Markdown href         | Rendered href       |
| --------------------- | ------------------- |
| `routing.mdx`          | `/en/docs/routing/` |
| `/docs/routing.mdx`    | `/en/docs/routing/` |
| `/de/docs/routing.mdx` | `/de/docs/routing/` |

Try each link:
- [Relative routing link](routing.mdx)
- [Root-absolute routing link](/docs/routing.mdx)
- [Explicit German routing link](/de/docs/routing.mdx)
