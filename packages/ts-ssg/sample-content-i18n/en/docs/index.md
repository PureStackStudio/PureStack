# Documentation

This page is generated from `en/docs/index.md` and published at `/en/docs/`.

It demonstrates localized navigation roots. The site config declares
`navigation.roots: ["docs"]`, and the builder resolves that root under each
locale folder: `en/docs` for English and `de/docs` for German.
