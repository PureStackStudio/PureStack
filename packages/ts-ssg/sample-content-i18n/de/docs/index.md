# Dokumentation

Diese Seite wird aus `de/docs/index.md` erzeugt und unter `/de/docs/`
veroeffentlicht.

Sie zeigt lokalisierte Navigationswurzeln. Die Site Config setzt
`navigation.roots: ["docs"]`, und der Builder loest diese Wurzel pro Sprache
auf: `en/docs` fuer Englisch und `de/docs` fuer Deutsch.

Weiter mit [Routing](routing.md), oder direkt zum Verhalten von
[Content Links](links.md).
