# Content Links

Der Markdown Compiler schreibt Links auf `.md`, `.mdx` und `.rmdx` Dateien zu
oeffentlichen Routen um. In einer i18n Site fliesst die aktuelle Quellsprache
in diese Entscheidung ein.

| Markdown href         | Gerenderter href    |
| --------------------- | ------------------- |
| `routing.mdx`          | `/de/docs/routing/` |
| `/docs/routing.mdx`    | `/de/docs/routing/` |
| `/en/docs/routing.mdx` | `/en/docs/routing/` |

Probiere die Links aus:
- [Relativer Routing Link](routing.mdx)
- [Root-absoluter Routing Link](/docs/routing.mdx)
- [Expliziter englischer Routing Link](/en/docs/routing.mdx)

Nutze die Vor/Zurueck Links unten, um die lokalisierte `_nav.json` Reihenfolge
zu pruefen.
