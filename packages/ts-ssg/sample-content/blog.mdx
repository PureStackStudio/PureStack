# Building Fast Docs With PureStack

Welcome to this sample blog page. It is intentionally written to exercise common MDX features in one place.

## Why This Page Exists

This page demonstrates:

- frontmatter metadata
- heading hierarchy
- inline code and fenced code blocks
- lists, quotes, and tables
- internal and external links

## Quick Setup

```bash
yarn install
yarn build
yarn dev
```

If the dev server starts successfully, your content pipeline is wired correctly.

## Example Snippet

```ts
type PostMeta = {
  title: string
  slug: string
  publishedAt: string
  tags: string[]
}

export function formatPost(meta: PostMeta): string {
  return `${meta.title} (${meta.publishedAt})`
}
```

## Rendering Notes

> MDX lets you mix markdown structure with component-friendly syntax while keeping content readable.

Use relative links like [Getting Started](./getting-started) for local docs and absolute links like [GitHub](https://github.com) for external resources.

## Comparison Table

| Concern        | Markdown | MDX |
| -------------- | -------- | --- |
| Basic prose    | Great    | Great |
| Components     | No       | Yes |
| Type-safe docs | Limited  | Better with tooling |

## Practical Authoring Tips

1. Keep one idea per section.
2. Prefer short paragraphs.
3. Use code fences with language identifiers.
4. Keep examples runnable where possible.
