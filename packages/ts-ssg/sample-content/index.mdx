# CalcCore

## Backend-native calculation engine  
### Excel-compatible logic, designed for production systems

CalcCore is a **headless calculation engine** for SaaS backends and internal platforms.

It enables teams to **define complex calculation logic using familiar Excel-style formulas or code**, and **execute that logic deterministically and efficiently inside backend services**.

CalcCore focuses on correctness, predictability, and long-term maintainability in production environments.

---

## Why CalcCore exists

Many backend systems rely on complex calculation logic:

- pricing and discount models  
- financial and accounting rules  
- forecasting and planning logic  
- eligibility and decision rules  

In practice, this logic is often designed and validated using spreadsheets, then reimplemented in code for production use.

CalcCore bridges this gap by providing a **dedicated calculation runtime** that can execute spreadsheet-style logic directly in backend systems, with production-grade guarantees.

---

## What CalcCore provides

### Backend-oriented execution model
CalcCore is designed for:
- APIs and services
- background jobs
- batch processing
- high-throughput workloads

It integrates naturally into modern backend architectures.

---

### Deterministic and reproducible calculations
CalcCore emphasizes predictable behavior:

- explicit evaluation semantics  
- controlled recalculation behavior  
- consistent results for identical inputs  

This makes calculations easier to test, debug, and reproduce over time.

---

### Familiar formula semantics
CalcCore supports a wide range of **Excel-compatible functions and behaviors**, including:

- arithmetic and logical expressions  
- lookup and reference functions  
- financial and date/time calculations  
- array-oriented and table-style logic  

Teams can work with familiar concepts without introducing a new modeling language.

---

### Flexible model authoring
Calculation models can be authored in multiple ways:

- **Code-first**, for engineering-owned logic and CI-driven workflows  
- **Excel-based**, for scenarios where spreadsheet authoring and validation are preferred  

Both approaches compile into the same execution model at runtime.

---

### Designed for observability
CalcCore exposes rich execution information:

- structured error reporting  
- dependency-aware evaluation  
- optional calculation traces  

This supports debugging, auditing, and long-term operational confidence.

## Example: pricing logic in a backend service

```csharp
var model = Model.Create("pricing:v1", m =>
{
    var age        = m.Input.Number("customer.age");
    var orderTotal = m.Input.Number("order.total");

    var discount =
        m.If(age >= 60, 0.15,
        m.If(orderTotal >= 200, 0.10, 0.00));

    m.Output("price.final",
        orderTotal * (1 - discount) * 1.19);
});

var engine = new EvaluationEngine(model);

var result = engine.Evaluate(new
{
    customer = new { age = 42 },
    order    = new { total = 199.90 }
});
```

This model can be evaluated repeatedly with different inputs, producing consistent and predictable results suitable for production use.
