# ExpandablePanel Samples

`ExpandablePanel` is a disclosure-first card for settings pages, service summaries, and expandable account surfaces. It uses native `<details>` and `<summary>` semantics, so it works without client-side hydration.

## 5. Usage pattern

```html
<ExpandablePanel
  title="Panel title"
  description="Short supporting description"
  icon="iconoir:computer"
  badge="Optional"
  meta="Optional"
  tone="neutral|accent|info|success|warning|danger"
  open="true|false"
>
  Body content goes here.
  <Grid columns="1" columnsMd="2">
    <div>Use Grid or other components inside the default slot.</div>
    <div>No named body template is required.</div>
  </Grid>
</ExpandablePanel>

<ExpandablePanel tone="accent">
  <template name="summary">
    Replace the whole summary area here.
  </template>
  Body content goes here.
</ExpandablePanel>
```
