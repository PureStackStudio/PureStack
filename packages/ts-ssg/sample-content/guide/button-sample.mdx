# Button Component Samples

`Btn` is a static-safe action component with built-in tones, size scales, and optional icon placement.

## 11. Props reference

```html
<Btn
  tone="accent|neutral|ghost|info|success|warning|danger"
  size="sm|md|lg"
  type="button|submit|reset"
  icon="iconoir:code"
  iconPosition="start|end"
  iconOnly="true|false"
  ariaLabel="Accessible label for icon-only buttons"
  disabled="true|false"
  class="custom-class-name"
>
  Label content
</Btn>
```
