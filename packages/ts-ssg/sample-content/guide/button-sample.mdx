# Button Component Samples

`Btn` is a static-safe action component with built-in variants, size scales, and optional icon placement.

## 1. Default button

<Btn>Save changes</Btn>

## 2. Variants

<Btn variant="primary">Primary action</Btn>
<Btn variant="secondary">Secondary action</Btn>
<Btn variant="ghost">Ghost action</Btn>
<Btn variant="warning">Warning action</Btn>
<Btn variant="danger">Danger action</Btn>

## 3. Sizes

<Btn size="sm">Small</Btn>
<Btn size="md">Medium</Btn>
<Btn size="lg">Large</Btn>

## 4. Leading icon

<Btn icon="iconoir:code">Download report</Btn>

## 5. Trailing icon

<Btn icon="iconoir:pin-slash" iconPosition="end">Continue</Btn>

## 6. Icon-only controls

<Btn icon="iconoir:headset-help" iconOnly="true" ariaLabel="Search" />
<Btn icon="iconoir:pin" iconOnly="true" ariaLabel="Pin item" />
<Btn icon="iconoir:check" iconOnly="true" ariaLabel="Open settings" />

## 11. Props reference

```html
<Btn
  variant="primary|secondary|ghost|warning|danger"
  size="sm|md|lg"
  type="button|submit|reset"
  icon="iconoir:code"
  iconPosition="start|end"
  iconOnly="true|false"
  ariaLabel="Accessible label for icon-only buttons"
  disabled="true|false"
  class="custom-class-name"
>
  Label content
</Btn>
```
