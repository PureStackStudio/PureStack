# Tabs Component Samples

`Tabs`, `TabsHeader`, and `TabPane` are static-friendly components for showing grouped content.  
Each `TabPane` accepts normal slotted MDX content, including fenced code blocks.

## 2. Build configuration examples

<Tabs id="config-samples">
  <TabPane id="programmatic" label="Programmatic API" active="true">
    ```ts
    import path from 'node:path'
    import { buildSite } from '@purestack/ts-ssg'

    await buildSite({
      rootDir: process.cwd(),
      contentDir: path.join(process.cwd(), 'content'),
      outDir: path.join(process.cwd(), 'dist', 'site'),
      siteTitle: 'Acme Docs',
    })
    ```
  </TabPane>
  <TabPane id="json-config" label="siteConfig.json">
    ```json
    {
      "siteTitle": "Acme Docs",
      "outDir": "dist/site",
      "style": {
        "themes": ["light", "dark"]
      },
      "navigation": {
        "mode": "auto"
      }
    }
    ```
  </TabPane>
  <TabPane id="cli" label="CLI">
    ```bash
    yarn tsx packages/ts-ssg/src/index.ts serve \
      --content ./packages/ts-ssg/sample-content \
      --port 4173
    ```
  </TabPane>
</Tabs>
