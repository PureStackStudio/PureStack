# Doughnut Chart Samples

`DoughnutChart` renders crisp, static-friendly SVG charts from inline segment data. It is intentionally small: bring your own surrounding layout, legend, and story.

## 1. Revenue mix dashboard

<Panel tone="accent">
  <Grid columns="1" columnsLg="auto minmax(0, 1fr)" alignItems="center">
    <DoughnutChart
      title="Revenue mix"
      description="Revenue distribution across product, services, support, and training."
      centerLabel="Total"
      valueSuffix="%"
      size="260"
      thickness="16"
      :segments="[
        { label: 'Product', value: 52 },
        { label: 'Services', value: 24 },
        { label: 'Support', value: 14 },
        { label: 'Training', value: 10 },
      ]"/>
    <div>
      <Badge tone="success">Healthy mix</Badge>
      <h2>Balanced recurring revenue</h2>
      <p>
        The chart keeps its center readable while each slice remains real SVG
        geometry, so it stays sharp in static output and scales cleanly in
        responsive dashboards.
      </p>
      <Grid columns="1" columnsMd="2">
        <Panel variant="outline" tone="accent">
          <strong>52%</strong>
          <p>Product subscription revenue</p>
        </Panel>
        <Panel variant="outline" tone="info">
          <strong>24%</strong>
          <p>Professional services and onboarding</p>
        </Panel>
      </Grid>
    </div>
  </Grid>
</Panel>

## 4. Empty state

<Panel tone="ghost">
  <Grid columns="1" columnsMd="auto minmax(0, 1fr)" alignItems="center">
    <DoughnutChart
      title="No incidents"
      emptyLabel="No data"

      ]"/>
    <div>
      <h3>No chartable values yet</h3>

## 5. Props reference

```html
<DoughnutChart
  title="Accessible SVG title"
  description="Longer accessible description"
  ariaLabel="Optional aria-label override"
  centerLabel="Total"
  centerValue="Custom center value"
  emptyLabel="No data"
  valueSuffix="%"
  size="220|12rem|100%"
  thickness="14"
  gap="2"
  startAngle="-90"
  tone="neutral|accent|info|success|warning|danger|ghost|feature|secondary|custom"
  variant="none|surface|outline|..."
  :segments="[
    { label: 'Product', value: 64 },
    { label: 'Services', value: 36, color: '#f4a261' },
  ]"
/>
```
