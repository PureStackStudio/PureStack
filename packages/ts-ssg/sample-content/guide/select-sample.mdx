# Select Component Samples

`FormSelectField` gives forms a polished native select without giving up browser semantics, keyboard behavior, or regular form submission.

## 1. Inline options

<AppForm action="/workspace/settings" method="post" tone="accent">
  <Grid columns="1" columnsMd="2">
    <FormSelectField
      label="Workspace region"
      name="region"
      placeholder="Choose a region"
      required="true"
      :options="[
        { label: 'US East', value: 'us-east' },
        { label: 'US West', value: 'us-west' },
        { label: 'Europe Central', value: 'eu-central' },
        { label: 'Asia Pacific', value: 'apac' },
      ]"/>
    <FormSelectField
      label="Release channel"
      name="releaseChannel"
      placeholder="Select channel"
      :options="[
        { label: 'Stable', value: 'stable' },
        { label: 'Preview', value: 'preview' },
        { label: 'Canary', value: 'canary', disabled: true },
      ]"/>
  </Grid>

  <FormStatus tone="accent">
    Inline option arrays keep static MDX pages expressive without requiring a
    separate script block.
  </FormStatus>
  <FormSubmit label="Save workspace"/>
</AppForm>

## 5. Props reference

```html
<FormSelectField
  label="Field label"
  tone="optional tone override"
  variant="surfaceAlt|surface|outline|subtle|..."
  name="fieldName"
  placeholder="Choose one"
  autocomplete="..."
  required="true|false"
  disabled="true|false"
  icon="iconoir:headset-help"
  iconEnd="lucide:chevron-down"
  :options="[
    { label: 'Option label', value: 'option-value' },
    { label: 'Disabled option', value: 'disabled-option', disabled: true },
  ]"
/>
```
