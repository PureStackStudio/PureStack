# Form Component Samples

`AppForm` and the related form primitives are built for tone-aware forms that stay clean in static MDX while still supporting richer layouts.

## 1. Basic contact form

<AppForm tone="accent" action="/contact" method="post" tone="accent">
  <FormInputField
    label="Full name"
    type="text"
    name="fullName"
    placeholder="Ada Lovelace"
    autocomplete="name"
    required="true"/>
  <FormInputField
    label="Email address"
    type="email"
    name="email"
    placeholder="ada@analytical.engine"
    autocomplete="email"
    required="true"/>
  <FormInputField
    label="Company"
    type="text"
    name="company"
    placeholder="PureStack Labs"
    autocomplete="organization"/>
  <FormSubmit label="Send inquiry"/>
</AppForm>

## 13. Props reference

```html
<AppForm action="/submit" method="post" tone="neutral|accent|info|success|warning|danger|ghost|feature|secondary|custom">
  <FormInputField
    label="Field label"
    tone="optional override"
    type="text|email|number|url|date|..."
    name="fieldName"
    placeholder="..."
    autocomplete="..."
    required="true|false"
    min="..."
    max="..."
    step="..."
    value="..."
    icon="iconoir:user"
    iconEnd="iconoir:search"
  />

  <FormCheck label="Accept terms" name="terms" value="yes" checked="true|false" />
  <FormAssistLink href="/help" label="Need help?" />
  <FormDivider label="Optional section" />
  <FormStatus tone="info|success|warning|danger|accent|neutral|ghost">
    Status message
  </FormStatus>
  <FormSubmit label="Continue" tone="optional override" />
</AppForm>
```
