There are no usage-based surprises and no per-cell or per-formula limits.

## What is included

All licenses include:

- Deterministic calculation engine
- Code-first and Excel-compatible model authoring
- Dependency-aware and incremental recalculation
- Structured inputs and outputs
- Error diagnostics and explainability APIs
- Access to documentation and updates within the licensed version

---

## Licensing model

CalcCore uses a **per-service licensing model**:

- A *service* is a deployed backend application or workload that embeds CalcCore.
- There are no limits on:
  - number of formulas
  - number of cells
  - number of executions
  - number of end users

This model is intended to align naturally with modern SaaS and backend architectures.

---

## Open and closed components

CalcCore is a commercial product.

Some auxiliary tools or examples may be open-sourced, but the core runtime and compiler are commercially licensed to ensure long-term maintenance and support.

## Frequently asked questions

### Can I start with the Developer License and upgrade later?
Yes. You can begin with a Developer License and upgrade to a SaaS Runtime or Business-Critical license when moving to production.

### Do you offer trials?
A time-limited evaluation license is available upon request.

### Is pricing affected by usage volume?
No. CalcCore pricing is not based on execution count, data size, or number of models.

### Can CalcCore be used in on-premise environments?
Yes. CalcCore can be deployed in cloud, hybrid, or on-premise environments under the same licensing terms.
