# Button Group Samples

`BtnGroup` is for moments where one action should stay close to its related alternatives. The default slot stays completely open: put `Btn`, `BtnLink`, and ordinary markup wherever the action model needs them.

## 6. Props reference

```html
<BtnGroup align="start|center|end" wrap="true|false">
  <Btn>Default action</Btn>
  <BtnGroupDropDown
    label="More"
    icon="lucide:chevron-down"
    iconPosition="start|end"
    iconOnly="true|false"
    ariaLabel="Accessible label for icon-only menus"
    tone="accent|neutral|ghost|info|success|warning|danger"
    size="sm|md|lg"
    variant="solid|surface|surfaceAlt|outlineFill|outline|subtle|subtleBtn|link"
    menuTone="neutral"
    menuVariant="surfaceAlt"
    align="start|end"
  >
    <Btn>Second action</Btn>
    <BtnLink href="/guide/">Link action</BtnLink>
    <div>Custom markup</div>
  </BtnGroupDropDown>
</BtnGroup>
```
