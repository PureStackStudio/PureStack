# Line Chart Samples

`LineChart` renders crisp, static-friendly SVG trend lines from inline series data. It is small on purpose: bring the surrounding narrative, let the component own the geometry.

## 1. Runtime adoption trend

<Panel tone="accent" variant="surfaceAlt">
  <Grid columns="1" columnsLg="minmax(0, 1fr) 18rem" alignItems="center">
    <LineChart
      title="Runtime adoption trend"
      description="Monthly adoption across core and edge runtimes."
      valueSuffix="%"
      showArea="false"
      :series="[
        {
          label: 'Core',
          points: [
            { label: 'Jan', value: 34 },

            { label: 'Apr', value: 57 },
            { label: 'May', value: 64 },
            { label: 'Jun', value: 73 },
          ],
        },
        {
          label: 'Edge',
          points: [
            { label: 'Jan', value: 12 },
            { label: 'Feb', value: 19 },
            { label: 'Mar', value: 28 },
            { label: 'Apr', value: 36 },
            { label: 'May', value: 48 },

        compact axis labels keep the chart readable in dense dashboards.

</Panel>

## 5. Props reference

```html
<LineChart
  title="Accessible SVG title"
  description="Longer accessible description"
  ariaLabel="Optional aria-label override"
  emptyLabel="No data"
  valueSuffix="%"
  width="100%|520|32rem"
  height="auto|320|20rem"
  minValue="-40"
  maxValue="100"
  curve="smooth|linear"
  animated="true|false"
  showArea="true|false"
  showPoints="true|false"
  showValues="true|false"
  showLabels="true|false"
  showAxis="true|false"
  tone="neutral|accent|info|success|warning|danger|ghost|feature|secondary|custom"
  variant="none|surface|outline|..."
  :series="[
    {
      label: 'Core',
      color: '#22c55e',
      points: [
        { label: 'Jan', value: 34 },
        { label: 'Feb', value: 42 },
      ],
    },
  ]"
/>
```
