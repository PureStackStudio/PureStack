# AlertBox Samples

`AlertBox` is a rich, theme-aware callout component for inline notices, warnings, release notes, and action prompts.

## 1. Basic informational alert

<AlertBox
  tone="info"
  title="Heads up: API contract update"
  meta="Updated 2 hours ago"
>
  The `v2` API response now includes `traceId` in every payload. Existing clients remain compatible.
</AlertBox>

## 2. Success alert with actions

<AlertBox
  tone="success"
  title="Deployment completed"
  badge="Stable"
  eyebrow="Release"
  icon="check"
  meta="Build #1042 finished in 3m 12s"
>
  Your production rollout passed smoke tests and latency checks. No regressions detected in core endpoints.
  <template name="actions">
    <a href="#release-notes">View release notes</a>
    <a href="#observability">Open observability dashboard</a>
  </template>
</AlertBox>

## 3. Warning alert in outline mode

<AlertBox
  tone="warning"
  variant="outline"
  title="Planned maintenance window"
  icon="clock"
  meta="Sunday 01:00 - 02:00 UTC"
>
  During maintenance, background job throughput may be reduced.
  <ul>
    <li>Read operations stay available.</li>
    <li>Retry failed writes after the maintenance window.</li>
    <li>Webhook delivery can be delayed by a few minutes.</li>
  </ul>
</AlertBox>

## 8. Content-rich alert with code and list

<AlertBox
  tone="info"
  title="Recommended hardening steps"
  icon="shield"
>
  Before enabling public access:
  <ol>
    <li>Set strict `Content-Security-Policy` headers.</li>
    <li>Enable detailed request logging for error triage.</li>
    <li>Pin versions in deployment config and lockfiles.</li>
  </ol>
  Example config key:
  <p><code>security.csp.defaultSrc = 'self'</code></p>
</AlertBox>

## 9. Full prop showcase

```html
<AlertBox
  tone="info|success|warning|danger|accent|neutral"
  variant="soft|outline|feature"
  title="Alert title"
  eyebrow="Optional eyebrow"
  badge="Optional badge"
  meta="Optional metadata line"
  icon="check|clock|support|rocket|none"
  compact="true|false"
  inline="true|false"
  role="status|alert|note"
  live="off|polite|assertive"
>
  Body content goes here.
  <template name="actions">
    <a href="#">Action</a>
  </template>
</AlertBox>
```
