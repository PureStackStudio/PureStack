# AlertBox Samples

`AlertBox` is a small composition primitive for notices, operational updates, release prompts, and inline guidance. It now uses the shared `Panel`, `Flex`, `IconFrame`, and `Badge` primitives, so tone and variant behavior stays consistent with the rest of the system.

## Default

<Flex direction="column">
  <AlertBox title="Default info alert">
    AlertBox defaults to `tone="info"` and `variant="surface"` when no visual
    props are provided.
  </AlertBox>

  <AlertBox title="Text-only alert">
    This is the most compact shape: title plus body, no icon, no badge, no
    metadata.
  </AlertBox>

  <AlertBox>
    Body-only alerts work for quiet inline notes where a title would add more
    noise than clarity.
  </AlertBox>
</Flex>

## API Reference

```html
<AlertBox
  tone="info"
  variant="surfaceAlt"
  variantMode="stateless"
  eyebrow="Optional eyebrow"
  title="Alert title"
  badge="Optional badge"
  meta="Optional metadata"
  icon="lucide:info"
>
  Alert body content.

  <template #actions>
    <BtnLink href="#primary">Primary action</BtnLink>
    <BtnLink href="#secondary" variant="outline">Secondary action</BtnLink>
  </template>
</AlertBox>
```
