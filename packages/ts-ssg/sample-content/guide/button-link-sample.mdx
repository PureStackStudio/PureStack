# Button Link Component Samples

`BtnLink` is the anchor-based companion to `Btn`. It keeps the same visual language while rendering real `<a href="...">` links for navigation and crawlable CTAs.

## 9. Props reference

```html
<BtnLink
  href="/your-target/"
  tone="accent|neutral|ghost|info|success|warning|danger"
  size="sm|md|lg"
  icon="iconoir:code"
  iconPosition="start|end"
  iconOnly="true|false"
  ariaLabel="Accessible label for icon-only links"
  target="_blank"
  rel="noopener noreferrer"
  class="custom-class-name"
>
  Label content
</BtnLink>
```
