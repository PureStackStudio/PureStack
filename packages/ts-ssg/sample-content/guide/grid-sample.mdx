# Grid Component Samples

`Grid` is a responsive layout primitive that stays static-render friendly and accepts breakpoint parameters.

## 1. Basic responsive columns

<Grid columns="1" columnsSm="2" columnsLg="4">
  <AlertBox tone="info" title="Alpha"  icon="iconoir:sphere">First card</AlertBox>
  <AlertBox tone="success" title="Beta" icon="iconoir:check">Second card</AlertBox>
  <AlertBox tone="warning" title="Gamma" icon="iconoir:x">Third card</AlertBox>
  <AlertBox tone="accent" title="Delta" icon="iconoir:star">Fourth card</AlertBox>
</Grid>

## 2. Custom template columns

<Grid columns="minmax(0, 1fr) auto" columnsLg="240px minmax(0, 1fr) auto">
  <AlertBox tone="neutral" title="Flexible content">
    Base layout uses `minmax(0, 1fr) auto`
  </AlertBox>
  <AlertBox tone="neutral" title="Content-sized sidebar">
    The trailing column keeps its natural width.
  </AlertBox>
  <AlertBox tone="neutral" title="Larger desktop template">
    `columnsLg` switches to a three-track template.
  </AlertBox>
</Grid>

## 3. Dense packing for uneven content

    One line
  </AlertBox>
  <AlertBox tone="info" title="Taller">
    This card intentionally has longer content to produce uneven heights across grid rows.
  </AlertBox>
  <AlertBox tone="info" title="Short">Two lines maybe.</AlertBox>

  </AlertBox>
  <AlertBox tone="info" title="Short">Compact block.</AlertBox>
  <AlertBox tone="info" title="Medium">

  </AlertBox>

## 5. Rich form layout with nested grids

<AppForm action="/contact" method="post">
  <Grid columns="1" columnsMd="2">
    <FormField
      label="First name"
      type="text"
      name="firstName"
      placeholder="Ada"
      autocomplete="given-name"
      required="true"
    />
    <FormField
      label="Last name"
      type="text"
      name="lastName"
      placeholder="Lovelace"
      autocomplete="family-name"
      required="true"
    />
  </Grid>

  <Grid columns="1" columnsLg="3">
    <FormField
      label="Work email"
      type="email"
      name="email"
      placeholder="ada@analytical.engine"
      autocomplete="email"
      required="true"
    />
    <FormField
      label="Team size"
      type="number"
      name="teamSize"
      min="1"
      max="5000"
      step="1"
      value="12"
    />
    <FormField
      label="Budget (EUR)"
      type="number"
      name="budget"
      min="1000"
      step="250"
      value="5000"
    />
  </Grid>

  <Grid columns="1" columnsMd="2" alignItems="start">
    <FormCheck
      label="Send me platform updates and release notes"
      name="updates"
      value="yes"
      checked="true"
    />
    <FormCheck
      label="I agree to the terms and data processing policy"
      name="terms"
      value="accepted"
      checked="true"
    />
  </Grid>

  <FormMeta>
    <Grid columns="1" columnsMd="2" alignItems="center">
      <FormAssistLink href="/guide/pricing" label="Need pricing details first?" />
      <FormAssistLink href="/contact" label="Talk to sales" />
    </Grid>
  </FormMeta>

  <FormStatus variant="info">
    This is a static sample. Submit action is shown for layout demonstration.
  </FormStatus>

  <Grid columns="auto auto 1fr" justifyItems="start">
      <FormSubmit label="Send request" />
      <FormSubmit label="Save draft" />
  </Grid>
</AppForm>

## 6. Props reference

```html
<Grid
  columns="1..12|<grid-template-columns>"
  columnsSm="1..12|<grid-template-columns>"
  columnsMd="1..12|<grid-template-columns>"
  columnsLg="1..12|<grid-template-columns>"
  columnsXl="1..12|<grid-template-columns>"
  alignItems="stretch|start|center|end"
  justifyItems="stretch|start|center|end"
  dense="true|false"
>
  ...
</Grid>
```
