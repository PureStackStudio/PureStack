# Bar Chart Samples

`BarChart` renders crisp, static-friendly SVG bars from inline item data. It is built for compact dashboards and comparison panels where the chart should stay readable without bringing a full charting runtime.

## 1. Runtime adoption

<Panel tone="accent" variant="surfaceAlt">
  <Grid columns="1" columnsLg="minmax(0, 1fr) 18rem" alignItems="center">
    <BarChart
      title="Runtime adoption"
      description="Adoption across core, edge, workers, services, and labs runtimes."
      valueSuffix="%"
      :items="[
        { label: 'Core', value: 64 },
        { label: 'Edge', value: 48 },
        { label: 'Workers', value: 37 },
        { label: 'Services', value: 28 },
        { label: 'Labs', value: 12 },
      ]"/>
    <div>
      <Badge tone="success">Momentum</Badge>
      <h2>Core stays strong while edge adoption rises</h2>
      <p>
        Bars, grid lines, value labels, and hover states are real SVG elements,
        so the chart stays sharp in static output and scales cleanly inside
        dense dashboard layouts.
      </p>
    </div>
  </Grid>
</Panel>

## 5. Props reference

```html
<BarChart
  title="Accessible SVG title"
  description="Longer accessible description"
  ariaLabel="Optional aria-label override"
  emptyLabel="No data"
  valueSuffix="%"
  width="520|32rem|100%"
  height="320|20rem|100%"
  minValue="-40"
  maxValue="100"
  animated="true|false"
  showValues="true|false"
  showLabels="true|false"
  showAxis="true|false"
  tone="neutral|accent|info|success|warning|danger|ghost|feature|secondary|custom"
  variant="none|surface|outline|..."
  :items="[
    { label: 'Core', value: 64 },
    { label: 'Edge', value: 48, color: '#14b8a6' },
  ]"
/>
```
