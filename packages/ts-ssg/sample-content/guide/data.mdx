# Data views

The [workspace preview](/workspace/) uses `MetricStrip`, `LineChart`, and `BarChart` to tell one project story. All values are defined in the page. Replace them with data from your own source before treating the view as a real dashboard.

## Match the chart to the question

| Question | Useful component |
| --- | --- |
| How much is done now? | `MetricItem` |
| How did progress change? | `LineChart` |
| How do groups compare? | `BarChart` |
| How is a whole divided? | `DoughnutChart` |

## Show a composition clearly

The ring below shows an example allocation of the twelve ready tasks in the workspace. It is a different view of the same illustrative data: five product tasks, four design tasks, and three marketing tasks.

## Keep the source of truth clear

When connecting a real source, transform the values into the component's small input arrays. Keep labels, units, and time windows beside the data. For a dashboard, choose a refresh strategy and state when the numbers were last updated.

<AlertBox title="Illustrative values" tone="info">
  No chart on the Waypoint starter reflects a real customer, project, or product metric.
</AlertBox>
