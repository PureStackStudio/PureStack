# MultiAutoCompleteInput

`MultiAutoCompleteInput` owns a list of selected items while keeping a query input open for the next item. It is built for recipient fields, tag pickers, user assignment, and similar multi-value flows.

## 1. Runtime playground

Type a known recipient, select from the popup, or paste multiple addresses separated by commas, semicolons, or new lines.

## 2. Basic usage

```html
<MultiAutoCompleteInput
  label="Recipients"
  placeholder="Add a recipient"
  icon="lucide:mail"
  :items="recipients"
  :model="recipientQuery"
  :options="recipientOptions"
  :onCreateItem="createRecipientItem"
  :onSplitInput="splitRecipients"
/>
```

## 3. Custom row component

Use `rowComponent` when suggestions need more than a single label. The row receives the option, query, active state, selected state, disabled state, and index.

```html
<MultiAutoCompleteInput
  rowComponent="RecipientSuggestionRow"
  :items="recipients"
  :model="recipientQuery"
  :options="recipientOptions"
/>
```

## 4. Props reference

```html
<MultiAutoCompleteInput
  label="Field label"
  name="fieldName"
  placeholder="Add item"
  icon="lucide:mail"
  iconEnd="lucide:chevron-down"
  removeIcon="lucide:x"
  minLength="0"
  maxResults="10"
  openOnFocus="true|false"
  allowCustomValues="true|false"
  allowDuplicates="true|false"
  separators=",;"
  loading="true|false"
  loadingText="Loading suggestions"
  emptyText="No suggestions"
  rowComponent="CustomSuggestionRow"
  :items="selectedItemsRef"
  :model="queryRef"
  :options="options"
  :onCreateItem="createItem"
  :onOptionToItem="optionToItem"
  :onSplitInput="splitInput"
  @itemschange="handleItems($event.detail.items)"
  @optionselect="handleSelect($event.detail.option)"
/>
```
