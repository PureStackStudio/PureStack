# @purestack/ts-css-bootstrap

TypeScript-first utilities and baseline styles inspired by Bootstrap, built on top of `@purestack/ts-css`.

This package provides **reusable building blocks** (modules, helpers, and configuration) that you can compose in your own build pipeline.

## Highlights

- Bootstrap-style reboot/normalize for HTML elements.
- Responsive containers and a grid system.
- Utility classes for display, flexbox, spacing, sizing, text, borders, shadows, overflow, alignment, and more.
- Theme colors generated from a small palette with automatic variations.
- Fully customizable via `CssConfig`.

## Install

```bash
yarn add @purestack/ts-css-bootstrap
```

## Core API

All exports are available from the package root:

```ts
import {
  CssConfig,
  applyBootstrap,
  createBootstrapStyle,
  writeBootstrapCssFile,
  bootstrapModules,
} from '@purestack/ts-css-bootstrap'
```

### `createBootstrapStyle(config?, style?)`

Creates a `CssConfig`, prepares it, applies all modules, and returns `{ config, style }`.

```ts
import { createBootstrapStyle, writeBootstrapCssFile } from '@purestack/ts-css-bootstrap'

const { style } = createBootstrapStyle()
await writeBootstrapCssFile(style) // writes ./dist/css/ts-css-bootstrap.css
```

### `applyBootstrap(config, style)`

Applies all modules to an existing `Style` instance. Use this when you want to control the `Style` lifecycle yourself.

```ts
import { CssConfig, applyBootstrap } from '@purestack/ts-css-bootstrap'
import { Style } from '@purestack/ts-css'

const config = new CssConfig()
config.prepare()

const style = new Style()
applyBootstrap(config, style)
const css = await style.toPrettyCSS()
```

### `writeBootstrapCssFile(style, outputPath?)`

Convenience helper that writes the generated CSS to disk and ensures the output directory exists.

```ts
await writeBootstrapCssFile(style, './dist/css/ts-css-bootstrap.css')
```

### `bootstrapModules`

A map of all modules so you can pick exactly what you want.

```ts
import { CssConfig, bootstrapModules } from '@purestack/ts-css-bootstrap'
import { Style } from '@purestack/ts-css'

const config = new CssConfig()
config.prepare()

const style = new Style()
bootstrapModules.reboot(config, style)
bootstrapModules.grid(config, style)
bootstrapModules.spacing(config, style)
```

## What gets generated

All modules live in `src/core/*.ts`. High-level overview:

- `reboot`: element defaults (based on Normalize-style reset, customized)
- `color`: theme colors + opacity + hover variants
- `container`: responsive containers with Bootstrap-like breakpoints
- `grid`: rows, columns, offsets, row-cols, gutters
- `display`: display, position, visibility utilities
- `flex`: flex utilities + hstack/vstack
- `align`: alignment, float, z-index utilities
- `border`: border + rounded utilities
- `spacing`: margin, padding, gap utilities
- `size`: width/height/min/max utilities
- `text`: alignment, decoration, transform, truncate, font-size
- `overflow`: overflow utilities
- `shadow`: theme-colored shadows
- `misc`: opacity, order, user-select, pointer-events, cursor, clearfix, vr
- `modal`: base modal styles

## Configuration

Customize by editing or extending `CssConfig` (`src/cssConfig.ts`).

Common knobs:

- `breakpoints`: container and responsive helpers
- `colors`: base palette (variations generated by `prepare()`)
- `colorVariations`: how many lighter/darker steps to generate
- `spacers`: spacing scale for margin/padding/gap
- `rounded`: border-radius scale
- `grid`: column count and gutters
- typography: `fontFamilies`, `fontSizes`, `fontWeights`, `lineHeights`
- `opacities`: opacity utility values and color alpha variants

Example:

```ts
import { CssConfig, createBootstrapStyle } from '@purestack/ts-css-bootstrap'

const config = new CssConfig()
config.colors.purple = ['#7c3aed']
config.spacers[6] = '4rem'

const { style } = createBootstrapStyle(config)
```

## Utility class overview

This is a high-level summary of class names. See `src/core/*.ts` for exact output.

- Colors:
  - Foreground: `fg-{color}-{1..n}`
  - Background: `bg-{color}-{1..n}`
  - Border: `br-{color}-{1..n}`
  - Opacity variants: `*-op-{0|25|50|75|100}`
  - Hover variants: `fg-hover-...`, `bg-hover-...`, `br-hover-...`
- Spacing:
  - Padding: `p-*`, `px-*`, `py-*`, `pt-*`, `pb-*`, `ps-*`, `pe-*`
  - Margin: `m-*`, `mx-*`, `my-*`, `mt-*`, `mb-*`, `ms-*`, `me-*`
  - Gap: `gap-*`, `row-gap-*`, `column-gap-*`
- Sizing:
  - Width: `w-25`, `w-50`, `w-75`, `w-100`, `w-auto`
  - Height: `h-25`, `h-50`, `h-75`, `h-100`, `h-auto`
  - Viewport: `vw-100`, `vh-100`, `min-vw-100`, `min-vh-100`, etc.
- Display + visibility:
  - `d-*` (block, flex, grid, none, etc.)
  - `position-*` (static, relative, absolute, fixed, sticky)
  - `visible`, `hidden`, `collapse`
- Flex:
  - `flex-direction-*`, `flex-grow-*`, `flex-shrink-*`, `flex-wrap-*`
  - `flex-fill`, `hstack`, `vstack`
- Alignment:
  - `valign-*`, `float-*`, `justify-content-*`, `align-items-*`, `align-self-*`, `align-content-*`
  - `z-index` helpers (e.g. `z-index-10`, `z-index-n10`)
- Borders:
  - `border`, `border-0`, `border-top`, `border-bottom`, etc.
  - `border-{1..5}`, `rounded-*` and directional rounded variants
- Text:
  - `text-start|end|center`, `text-uppercase|lowercase|capitalize`
  - `text-wrap|nowrap|break`, `text-truncate`
  - `decoration-underline|line-through|none`
  - `fs-{1..6}`
- Overflow:
  - `overflow-*`, `overflow-x-*`, `overflow-y-*`
- Misc:
  - `opacity-*`, `opacity-hover-*`
  - `order-*`, `user-select-*`, `pe-*`, `cursor-pointer`, `clearfix`, `vr`
- Shadows:
  - `shadow-{color}{index}`, `shadow-hover-{color}{index}`, `shadow-1`

## Grid and containers

Breakpoints and container widths are defined in `CssConfig.breakpoints` (defaults match common Bootstrap values).

Grid utilities include:

- `.row`, `.col`, `.col-{n}`, `.col-{bp}-{n}`
- `.offset-{n}`, `.offset-{bp}-{n}`
- `.row-cols-{n}`, `.row-cols-{bp}-{n}`
- Gutter helpers: `.g-1`, `.gx-1`, `.gy-1` (currently only `1`)
