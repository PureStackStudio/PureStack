# @purestack/ts-css-bootstrap

TypeScript-driven CSS generator that produces a compact, Bootstrap-inspired utility set and baseline reboot styles using `@purestack/ts-css`.

This package is **not** a runtime CSS framework. It is a **build-time generator**: importing or executing the entry module writes a CSS file to `./dist/css/ts-css-bootstrap.css`.

## What it generates

- Reboot / normalize styles for HTML elements (typography, forms, tables, etc.).
- Responsive container widths with Bootstrap-like breakpoints.
- Grid system with rows, columns, offsets, and gutters.
- Utility classes for display, flexbox, alignment, spacing, sizing, overflow, text, borders, shadows, opacity, and more.
- Color scale utilities (foreground, background, border) and hover variants generated from a small theme palette.

## Output

- File: `dist/css/ts-css-bootstrap.css`
- Generated by: `src/index.ts`
- Uses: `@purestack/ts-css` `Style` builder

## Install

```bash
yarn add @purestack/ts-css-bootstrap
```

## Quick start

From this package folder:

```bash
yarn build
node dist/ts-css-bootstrap.js
```

That will write `dist/css/ts-css-bootstrap.css`.

## How it works

The entry file `src/index.ts` creates a `CssConfig` and a `Style`, then runs a series of modules that append selectors and declarations:

- `reboot`: element defaults (based on Normalize-style reset, customized)
- `color`: generated theme colors + opacity variants
- `container`: `.container` / breakpoint containers
- `align`: alignment, float, z-index utilities
- `border`: borders + rounded utilities
- `display`: display + position + visibility
- `flex`: flex utilities + hstack/vstack
- `font`: font style and weight utilities
- `grid`: grid row/column system
- `misc`: object-fit, opacity, order, user-select, pointer-events, cursor, etc.
- `overflow`: overflow utilities
- `size`: width/height/min/max utilities
- `shadow`: theme-colored shadow utilities
- `spacing`: margin/padding/gap utilities
- `text`: text alignment, transform, decoration, truncation, font-size
- `modal`: base modal styles

## Customization

Edit `src/cssConfig.ts` to change theme defaults, then rebuild.

Key knobs:

- `breakpoints`: controls container and grid responsive widths.
- `colors`: base theme palette. Variants are generated automatically by `prepare()`.
- `colorVariations`: number and range of lighter/darker steps for each color.
- `spacers`: numeric spacing scale used by padding/margin/gap.
- `rounded`: border radius scale.
- `grid`: column count and gutter setup.
- typography: `fontFamilies`, `fontSizes`, `fontWeights`, `lineHeights`.
- `opacities`: used for color opacity variants and utility classes.

After updating config, run the generator again to emit new CSS.

## Utility class overview

This is a high-level summary of class names. See `src/core/*.ts` for exact output.

- Colors:
  - Foreground: `fg-{color}-{1..n}`
  - Background: `bg-{color}-{1..n}`
  - Border: `br-{color}-{1..n}`
  - Opacity variants: `*-op-{0|25|50|75|100}`
  - Hover variants: `fg-hover-...`, `bg-hover-...`, `br-hover-...`
- Spacing:
  - Padding: `p-*`, `px-*`, `py-*`, `pt-*`, `pb-*`, `ps-*`, `pe-*`
  - Margin: `m-*`, `mx-*`, `my-*`, `mt-*`, `mb-*`, `ms-*`, `me-*`
  - Gap: `gap-*`, `row-gap-*`, `column-gap-*`
- Sizing:
  - Width: `w-25`, `w-50`, `w-75`, `w-100`, `w-auto`
  - Height: `h-25`, `h-50`, `h-75`, `h-100`, `h-auto`
  - Viewport: `vw-100`, `vh-100`, `min-vw-100`, `min-vh-100`, etc.
- Display + visibility:
  - `d-*` (block, flex, grid, none, etc.)
  - `position-*` (static, relative, absolute, fixed, sticky)
  - `visible`, `hidden`, `collapse`
- Flex:
  - `flex-direction-*`, `flex-grow-*`, `flex-shrink-*`, `flex-wrap-*`
  - `flex-fill`, `hstack`, `vstack`
- Alignment:
  - `valign-*`, `float-*`, `justify-content-*`, `align-items-*`, `align-self-*`, `align-content-*`
  - `z-index` helpers (e.g. `z-index-10`, `z-index-n10`)
- Borders:
  - `border`, `border-0`, `border-top`, `border-bottom`, etc.
  - `border-{1..5}`, `rounded-*` and directional rounded variants
- Text:
  - `text-start|end|center`, `text-uppercase|lowercase|capitalize`
  - `text-wrap|nowrap|break`, `text-truncate`
  - `decoration-underline|line-through|none`
  - `fs-{1..6}`
- Overflow:
  - `overflow-*`, `overflow-x-*`, `overflow-y-*`
- Misc:
  - `opacity-*`, `opacity-hover-*`
  - `order-*`, `user-select-*`, `pe-*`, `cursor-pointer`, `clearfix`, `vr`
- Shadows:
  - `shadow-{color}{index}`, `shadow-hover-{color}{index}`, `shadow-1`

## Grid and containers

Breakpoints and container widths are defined in `CssConfig.breakpoints` (defaults match common Bootstrap values).

Grid utilities include:

- `.row`, `.col`, `.col-{n}`, `.col-{bp}-{n}`
- `.offset-{n}`, `.offset-{bp}-{n}`
- `.row-cols-{n}`, `.row-cols-{bp}-{n}`
- Gutter helpers: `.g-1`, `.gx-1`, `.gy-1` (currently only `1`)
